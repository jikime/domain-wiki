# 채팅 사용 흐름 개선

적용일: 2026-09-09. hince의 흰 바탕·모브 로즈·직각·구분선과 공식 shadcn 입력 컴포넌트를 유지한다.

## 사용 흐름

- 새 대화에는 짧은 안내와 중앙 입력창을 보여준다. 첫 질문을 전송하면 대화를 저장하고, 입력창은 대화 아래에 유지한다.
- 왼쪽에 새 대화·최근 대화·제목 검색을 모았다. 검색은 서버가 반환한 본인의 최근 최대 100개 대화에 적용한다. 모바일에서는 공식 Sheet로 대화 목록을 연다.
- 도메인·프로젝트는 입력창 안의 선택 버튼으로 표시한다. 기존 대화의 범위는 선택 즉시 서버에 저장하고, 저장 중에는 전송을 막는다. 저장 실패 시 이전 범위로 복구한다. 새 대화의 범위는 첫 질문과 함께 저장한다.
- 자료·위키에서 시작한 대화는 접근 가능한 공개 자료의 제목과 링크를 표시한다. 자료 한정 해제와 다음 질문의 범위 변경을 유지한다.
- 답변의 인용 번호 또는 참고 자료 버튼을 누르면 해당 답변의 원문 근거를 연다. 1100px보다 넓은 화면은 옆 패널, 좁은 화면은 공식 Sheet를 사용한다. 닫기와 Escape 후 선택한 버튼으로 포커스를 돌려준다.
- 스트리밍 중 찾은 후보 자료와 완료 후 실제 사용한 근거를 구분한다. 원문 버전·문단 링크, 철회된 근거의 제한을 유지한다. 코드와 기존 링크 안의 인용 표시는 변환하지 않는다.
- Enter는 전송, Shift+Enter는 줄바꿈이다. 한글 조합 상태와 키 코드 229에서는 전송하지 않는다. 입력창은 내용에 따라 늘어나며 최대 높이를 넘으면 내부에서 스크롤된다.
- 새 질문은 전송 직후 대화에 표시한다. 이전 내용을 읽는 동안 자동 스크롤을 멈추고, ‘최신 답변으로’ 버튼으로 다시 따라갈 수 있다.
- 생성 중지, 실패·취소 후 다시 질문, 답변 의견, 작성자의 지식 제안을 유지한다. 신고 내역과 대화 삭제는 상단의 대화 관리 창에 있다. 질문 없는 대화 저장도 이 창에서 사용할 수 있다.
- 답변 의견은 저장에 성공하면 입력 영역을 접고 ‘내 의견 확인’ 링크를 표시한다. 다시 열거나 새로고침해도 저장된 평가와 의견을 불러온다. 저장 실패 시 입력 내용을 유지하고 다시 보낼 수 있다. 작성자는 ‘내 신고와 답변 의견’에서 접수·확인 중·처리 완료 상태를, 검토 직원은 ‘검토함 → 답변 의견’에서 접수 내용을 확인한다.

## 화면과 검증

전체 기능 통합시험 75개, 프로덕션 빌드·TypeScript·Biome 검사를 통과했다. 실행 명령과 상세 결과는 [상위 검증 기록](../VERIFICATION.md)에 있다. 초기 화면 캡처에는 모델 연결 전 안내가 표시된다. 이후 OpenAI 실제 연결을 완료했으며 [최신 연결·출처 답변 확인](../../../openai/VERIFICATION.md)에 기록했다. 통합시험은 별도 시험 DB와 고정 응답 모델로 대화·권한·중지·인용 동작을 검증한다.

답변 의견 후속 수정은 `npm run test:integration -- --grep '답변 의견은 저장 후'`로 검증했다. 별도 시험 DB의 완료 답변을 사용해 데스크톱 1440px와 모바일 390px에서 저장 실패 후 입력 유지·재전송·자동 접힘·포커스 복귀·기존 내용 복원·중복 없는 수정·본인 내역 이동·검토함 반영을 확인했다. 추가 회귀 시험 1개와 프로덕션 빌드·TypeScript·변경 파일 Biome 검사를 통과했다.

## 구현 위치

- `src/components/chat-workspace.tsx`: 대화·입력·범위·목록·원문 패널.
- `src/components/chat-markdown.tsx`: 검증 가능한 본문 인용을 선택 버튼으로 연결.
- `src/styles/chat.css`: 채팅 전용 배치·높이·반응형 스타일.
- `src/server/services/retrieval.ts`: 기존 공개 지식 조건으로 선택한 자료의 표시 제목 조회.
- `tests/chat-cases.ts`: 대화 저장·한글 조합·범위 저장 실패·출처·스크롤·중지 검사.
