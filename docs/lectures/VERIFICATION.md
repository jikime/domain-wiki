# 실제 화면을 바탕으로 개편한 교육 자료 확인 기록

최신 확인은 아래의 **2026-10-28 · 첫 장 설명과 직접 확인 절차 보완**을 참고합니다. 앞선 기록의 과제 수와 시간 배분은 당시 자료 기준입니다.

확인일: 2026-10-26. 대상은 강의 HTML·워크북·강사용 준비 자료입니다. 이전의 공동 개발 과정에서 실제 화면과 맞지 않던 과제와 개발 시작 시점을 조정했습니다.

## 반영한 내용

- 준비된 샘플 위키 체험 → 개인 또는 배정 환경 준비 → 첫 화면 변경 → 회사 지식·작성 예시 → 선택 기능 구현·완성 → 시범 사용 → 운영 인계로 연결합니다.
- 4차수 중간부터 구현을 시작하고 5차수에도 같은 기능을 이어 갑니다. 모든 예제를 필수 과제로 주지 않습니다.
- 기존 기록 네 입력칸·RFP 확인 질문·채팅 범위 선택을 새 기능으로 소개하지 않습니다. 회사 예시, 검색 결과 단위 안내, 화면 이동 시 선택 유지, RFP 누락 표시를 개선 후보로 제시합니다.
- 공용 환경은 2차수에 담당과 접속 방식을 정하고 3–4차수 접속 확인, 5차수 통합 반영, 6차수 시범 사용, 7차수 운영 인계로 이어 갑니다.
- 7개 강의·112장·28개 작업을 같은 원고에서 생성했습니다. 터미널 명령을 제외한 27개 요청 예시에 문맥·해야 할 것·결과 포맷·예시를 넣었습니다.
- 실제 캡처 7개를 10개 슬라이드에 사용합니다. 현재 화면·논의할 질문·목표를 구분하며 확대에서도 같은 이미지를 보여 줍니다. 가상 자료를 넣고 로그인한 실제 화면으로, 제안 기능이 구현됐다는 뜻은 아닙니다.
- 각 작업은 순서·요청·완료 기준과 해당 강의 장의 링크로 구성합니다. 강사용 `coach` 내용과 수업 시간은 교육생 핵심 워크북에 내보내지 않습니다.
- 직접 작업은 240분 중 140분이며 준비·설계·구현·검증을 포함합니다. 설명이 짧게 끝나면 연속 작업 시간을 늘리고 휴식은 유지하도록 강사용 코칭표에 적었습니다.
