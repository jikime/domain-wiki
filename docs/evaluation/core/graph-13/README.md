# 13단계 실제 검색 회귀

2026-09-09, 실제 `gpt-5.6-terra`와 임베딩 모델로 이용 직원 계정의 질문을 실행했다. [원본 결과](results.json)에 질문·범위·답변·근거 위치·토큰·응답 시간·링크 검사를 보존했다. 고객 업무 판정은 미검증이다.

| 항목 | 결과 |
| --- | --- |
| 기존 9개 질문 | 후속 선행 질문 포함 10회 완료, 기대 구절 7/7을 상위 8개에서 유지 |
| 기존 질문 사용량 | 입력 13,732 / 출력 1,274토큰 |
| 긴 개정 문서 | 일반 범위와 ‘원문만 사용’ 모두 현재 45일 구절을 찾음 |
| 전체 11개 질문 | 후속 포함 12회, 입력 23,027 / 출력 1,455토큰 |
| 실행 시간 | 항목당 2.155~5.683초, 중앙값 3.347초 |
| 현재 의미 색인 | 평가 작업공간의 현재 대상 53/53, 새 전체 본문 식별자 사용 |
| 사용한 근거 링크 | 26개 모두 HTTP 200 |
| 화면 | 후속 질문·긴 문서·원문만 사용 × 1440/390px, 6개 조합에서 가로 넘침·브라우저 오류 없음 |

9단계의 결과를 덮어쓰지 않았다. 질문과 범위는 그대로 사용했지만, 이후 단계에서 같은 평가 도메인에 자료가 추가되었다. 따라서 이는 현재 데이터에서의 근거 회귀 검사이며, 모든 입력 데이터가 동일한 성능 비교는 아니다. 기존 9단계 입력 8,001토큰보다 이번 입력이 늘어난 데에는 도메인 목적·용어·상세 근거 문맥과 추가 자료가 함께 영향을 준다.

첫 Q05 답변에서 원문의 ‘반영 완료로 확인되지 않았다’를 ‘완료되지 않았다’로 강화한 문장을 발견했다. 상태의 불확실성과 검토 중인 변경안을 구분하도록 지시문을 수정했다. [Q05·Q09 각각 3회 재검사](../graph-13-status-recheck/results.json)에서 Q05는 완료 여부 미확인을 유지했고, Q09는 10초 변경 결정을 확정하지 않았다. 이 6회는 입력 9,366 / 출력 1,265토큰, 사용 링크 22개 HTTP 200, 4개 화면 조합 오류 없음이다. 최초 답변도 이력으로 남긴다. 모든 문장별 인용 의미를 자동 검증했다는 뜻은 아니다.

이 표본에서는 필요한 근거가 기본 검색에서도 발견되어 관계 추가 원문은 0개였다. 관계 탐색의 효과는 [별도 간접 관계 비교](../graph-13-indirect/README.md)에서 검사했다.

재현: `node scripts/evaluate-retrieval.mjs <새-평가-이름>`. 상태 표현 재검사는 `node scripts/evaluate-retrieval.mjs <새-평가-이름> --status-recheck`. 계정·키는 로컬 비공개 파일과 환경 설정으로만 읽는다.
