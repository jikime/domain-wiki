# 가상 은하군 관제 운영 지침

개발용 가상 표본이며 실제 고객 지침이나 법적 기준이 아닙니다. 이 지침은 가상 은하군의 시범 교차로 두 곳에만 적용합니다.

## 정상 갱신
정상 통신 상태에서는 관제 화면을 30초 간격으로 갱신합니다. 통신 장애 중에는 이 갱신 기준을 충족했다고 판정하지 않습니다.

## 통신 중단과 재연결
통신이 끊기면 마지막 수신 시각과 통신 중단 표시를 함께 보여 줍니다. 마지막 수신 값을 최신 값으로 표시하면 안 됩니다. 재연결 후 60초 안에 새 데이터 수신 여부를 확인합니다.

## 점검 기록
이 시범사업의 정상 장비 점검 기록은 72시간 보관합니다. 장애 장비의 기록에는 이 보관 기간을 적용하지 않습니다. 담당자는 두 교차로의 정상 통신과 통신 중단 상황을 각각 확인하고 결과를 기록합니다. 이 문서에는 사업 예산과 장애 장비의 보관 기간이 적혀 있지 않습니다.
