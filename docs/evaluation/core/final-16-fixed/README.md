# 16단계 고정 입력 재평가

실행일: 2026-09-10 한국시간. 개발용 가상 자료만 사용했다. 고객 업무 담당자의 전문 검토는 수행하지 않았다.

9단계 기준 평가와 동일한 원문 3개, 기준 위키 1개, Q01~Q09, `gpt-5.6-terra`로 새 작업공간에서 다시 실행했다. 직원 기록은 양쪽 모두 동일한 구조의 기록으로 등록했다. 원본 파일 SHA-256, 실제 저장된 원문 SHA-256, 추출 문단의 순서·본문·위치, 기준 위키 본문·메타데이터를 대조했다. 세 자료와 위키 모두 일치했다. 파일로 제공한 직원 기록은 앱에 구조화해 저장되므로 파일 해시와 저장 원문 해시는 다르며, **변경 전후 저장 원문끼리는 동일**하다.

| 질문 | 최종 답변 직접 대조 결과 |
| --- | --- |
| Q01 약어 | 이 도메인의 ITS를 지능형 교통체계로 설명 |
| Q02 정상 갱신 | 30초, 통신 장애 중 충족 판정 제외 |
| Q03 통신 단절 | 마지막 값을 최신 값으로 표시하면 안 됨 |
| Q04 후속 질문 | 선행 대화의 재연결 상황을 이어서 60초 확인 |
| Q05 직원 경험 | 작성자 판단과 제안이며 아직 검토 중, 반영 완료로 바꾸지 않음 |
| Q06 근거 부족 | 예산·지체상금은 원문에 없다고 안내 |
| Q07 적용 범위 | 개발 표본을 모든 도시의 법적 기준으로 확대하지 않음 |
| Q08 다른 사업 | 겨울시의 10초 기준을 별도 범위에서 확인 |
| Q09 유도 질문 | 새봄시가 10초로 변경했다는 근거는 현재 검색 범위에서 확인하지 못함 |

고정 구절 검사 7/7을 유지했고, 아홉 답변의 수치·부정문·범위와 인용을 직접 읽었다. Q09의 근거 부족 안내는 선택 범위에서 확인한 내용이며 전체 조직 문서의 부재를 증명하지 않는다.

| 사용량 | 9단계 기준 | 16단계 최종 |

| 실제 채팅 모델 호출 | 10 | 10 |
| 입력 토큰 | 8,001 | 14,421 |
| 출력 토큰 | 986 | 1,181 |
| 사용량 미확인 호출 | 0 | 0 |

Q04 선행 질문 1회도 합산했다. 비교 질문별 시간은 기준 1.64~5.63초, 최종 1.86~5.75초였다. 관계·근거 설명이 추가된 문맥으로 입력 사용량이 늘었다. 모델 가격을 확인하지 않았으므로 금액으로 환산하지 않는다. 이 표는 채팅 비교이며 별도 초안·요약 작업 사용량과 섞지 않았다.

자료: [입력 동일성과 전후 답변·사용량](comparison.json), [실행 결과](results.json). 재현: `node scripts/evaluate-core.mjs final-16-fixed --isolated`, `node scripts/compare-fixed-evaluation.mjs`. 완료한 같은 출력 폴더에 재실행하기 전에는 기존 평가 결과를 별도로 보존해야 한다.

모델의 확률적 응답과 제공자 내부 변경은 고정하지 않았다. 모델 이름·입력 자료·질문은 같고, 검색 문맥·지시문·처리 방식은 구현 변경의 비교 대상이다. [원본 네이티브 앱 비교](../reference-16/README.md)는 별도로 기록했다.
