# 원본 기능 복원 후 실제 모델 정리·개정 평가

2026-09-10 새 도메인과 새 원문 버전으로 다시 실행했다. 이전 12단계 평가 기록은 보존했다. 모델은 `gpt-5.6-terra`이며, 직접 작성한 가상 개발 자료를 사용했다. 실제 고객 자료와 업무 담당자의 판정은 포함하지 않는다.

| 항목 | 최초 정리 | 개정 정리 |
| --- | --- | --- |
| 위키·검토 묶음 | 4개·1묶음 | 기존 4개·1묶음 |
| 분석·생성 호출 | 8회 | 6회 |
| 입력·출력 토큰 | 36,241·5,225 | 29,856·4,256 |

[최초 원문](source-initial.md)의 운영 기록 보관 기간 한 문장을 30일에서 45일로 바꾼 [개정 원문](source-revision.md)을 등록했다. 원문 승인 뒤 분석·위키 생성·변경 묶음 작성으로 이어지고, 작성 직원의 검토 요청과 다른 검토 직원의 승인을 거쳐 게시했다.

생성 본문을 직접 대조했다. 관제 화면 30초, 모든 화면 일괄 적용 제외, 보조 화면 90초, 비상 전원 8시간, 구두 설명만으로 검수 완료 금지, 통신 단절 중 자동 갱신 금지, 재연결 후 새 데이터 확인, 다른 사업의 보관 기간 적용 금지를 보존했다. 개정 문서에는 현재 45일을 반영했고 과거 30일을 현재 조건으로 남기지 않았다. 기존 30일 본문은 이전 위키 버전에 남아 있다.

원문 하나에 속한 페이지는 복원한 원본 규칙에 따라 새 본문으로 교체한다. 개정된 3개 항목의 확인 표시를 공식 390px 편집 폼에서 처리하고 새 변경 묶음을 저장했다. 나머지 항목은 본문을 재사용했다. 모델이 만든 새 본문을 그대로 검토했으며, 예전처럼 기존 본문을 앞에 붙인 형태로 되돌리지 않았다. [직접 대조 기록](manual-review.json), [최초 결과](initial.json), [개정 결과](revision.json).

최초·개정 각각 자료 상세, 생성 작업, 검토 화면의 1440px·390px와 게시 문서의 390px를 확인했다. 총 14개 화면에서 HTTP 200, 가로 넘침 0, 브라우저 오류 0이다. 현재 원문 문단 근거와 게시된 문서 연결도 읽기 직원 계정으로 확인했다.

재현 명령은 `INGEST_EVALUATION_RUN=original-parity-20260910 node scripts/evaluate-ingest.mjs`이며, 본문 대조 후 `--publish`, 개정에는 `--revision`을 사용했다. `scripts/review-ingest-evaluation.mjs`의 해당 실행 분기는 이 고정 표본의 조건과 버전을 대조한다. 다른 작업을 자동 승인하는 도구가 아니다. 비밀 계정과 API 키는 보고서에 넣지 않는다.
