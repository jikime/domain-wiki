# 15단계 개발 자료 그래프 확인

실행: 2026-09-10. 13단계 간접 관계 및 14단계 품질 점검에서 공식 계정·실제 모델로 검증한 가상 게시 자료를 사용했다. 그래프 평가는 읽기 전용이며 추가 모델 호출은 0회다. [결과 JSON](result.json)에 범위·응답 지문·현재 버전·관계 입력·화면 시간·이동 링크를 기록했다.

| 자료 | 위키 / 관계 / 군집 | API 시간 | 응답 크기 | 데스크톱 / 모바일 계산 |
| --- | --- | --- | --- | --- |
| 간접 연결 표본 | 3 / 3 / 1 | 41.8ms | 1,531바이트 | 9.2 / 6.1ms |
| 개정 후 품질 표본 | 3 / 1 / 2 | 16.9ms | 1,467바이트 | 6.0 / 6.0ms |

1440px·390px 두 자료씩 총 4개 화면을 확인했다. 이동부터 결과 표시까지 458~614ms였고, 가로 넘침 0px·브라우저 오류 0건·검사한 본문/원문/질문/등록 링크 모두 200이었다. 모바일 목록↔그래프 전환, 같은 입력의 계산 재사용 전 서버 공개 상태 재확인도 통과했다. 상세 구절 자체는 본문과 원문 링크에서 확인한다.

화면을 직접 살펴보고 작은 군집이 중앙에 과하게 모이는 배치를 넓혔다. 최종 화면은 [간접 연결 데스크톱](indirect-1440.png), [모바일](indirect-390.png), [모바일 상세](indirect-detail-390.png), [품질 표본 데스크톱](quality-1440.png)에서 확인할 수 있다.

이 시간은 로컬 개발 서버의 최종 실행 관측값이다. 최초 컴파일이나 외부 운영 서버의 속도를 보장하지 않는다. 위 표는 소규모 자료이며 규모 검증은 별도 통합시험의 200개/397연결 계산 23.5ms, 4,000개 초과 관계 거부로 구분한다. 실제 고객 문서의 군집 유용성·공백 판단은 전문가 검토를 하지 않았다.

재현: 개발 서버가 실행되고 기존 13·14단계 평가 상태와 로컬 계정이 준비된 환경에서 `node scripts/evaluate-graph-view.mjs`를 실행한다. 결과에는 계정 비밀번호나 모델 키를 기록하지 않는다.
