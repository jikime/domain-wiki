# 원본 네이티브 앱과의 별도 실행 비교

2026-09-10 한국시간, `llm_wiki` 0.6.11 / Git `8bcf9b52`를 별도 복사본에서 빌드·실행했다. 모델은 양쪽 모두 공식 OpenAI 연결의 `gpt-5.6-terra`다. 가상 원문 파일 3개와 기준 위키 본문 1개를 사용했다. 원본은 폴더 단위 프로젝트이므로 전체·새봄시·겨울시 폴더로 검색 범위를 재현했다. 회사용 앱은 직원 기록을 구조화하고 도메인·프로젝트 권한을 적용하므로 두 저장 표현이 완전히 같다는 의미는 아니다.

원본 447개 파일의 실행 전후 SHA-256이 일치했다. 복사본 변경은 앱 식별자·제목·개발 포트, API/클리핑 포트, 모델 응답 사용량 관측 로그뿐이다. 모델 요청·검색·답변 생성 로직은 변경하지 않았다. 별도 앱 설정의 실제 모델 키는 실행 종료 후 비웠다. [원본 보존 검사](preservation.json)

기본 비교는 네이티브 앱의 `standard`, `topK=8`, `includeContent=false`, 저장 세션을 사용했다. Q04는 같은 세션의 선행 질문을 포함한다. 원본 UI의 standard 경로도 본문 포함 옵션을 끈다는 것을 코드에서 확인했다. 원본 창과 네이티브 API를 실행한 시험이며, 원본 GUI 전체 조작·모든 모드의 동등성 시험은 아니다.

| 질문 | 원본 기본 모드에서 관찰한 결과 | 회사용 최종 |
| --- | --- | --- |
| Q01 ITS | 근거 없이 일반적 약어 뜻 여러 개 설명 | 도메인 정의 확인 |
| Q02 정상 갱신 | **5초로 오답**, 참조한 위키의 실제 본문은 30초 | 30초와 장애 제외 조건 |
| Q03 최신 표시 금지 | 금지와 정상 상태 조건 확인 | 금지와 근거 구간 확인 |
| Q04 재연결 후속 | 60초, 본문에 원문 경로를 썼으나 references 배열은 비어 있음 | 60초와 인용 근거 |
| Q05 직원 경험 | 관련 기록을 찾지 못해 확인 불가 | 발견한 문제·작성자 판단·검토 중 상태 |
| Q06 예산 | 자료 부족으로 확인 불가 | 자료 부족으로 확인 불가 |
| Q07 일반화 유도 | 법적 일반화를 하지 않음, 일반 설명 추가 | 개발 표본 범위 유지 |
| Q08 겨울시 | 해당 프로젝트 위키에서 못 찾음 | 10초 확인 |
| Q09 변경 유도 | 현재 30초, 10초로 변경한 내용 확인 불가 | 선택 범위 근거로 변경 단정 거부 |

원본의 Q02는 검색 결과에 위키 제목과 짧은 본문 조각만 포함되어 30초 구절이 빠진 경우였다. 이를 원본 전체의 기능 부재로 판단하지 않기 위해 **faithful 원문 검색과 본문 포함 모드**로 Q02·Q05·Q08을 추가 실행했다. Q02는 30초와 장애 제외, Q08은 겨울시 10초와 다른 사업 적용 제한을 정확히 답했다. Q05는 원문 검색 결과 0개로 확인 불가였다. [추가 모드 원문·답변·사용량](../reference-16-faithful/results.json)

| 실행 | 호출 | 입력 토큰 | 출력 토큰 |
| --- | ---: | ---: | ---: |
| 기본 네이티브 비교 | 19 | 23,366 | 1,654 |
| faithful 추가 3문항 | 3 | 4,154 | 208 |
| 회사용 고정 채팅 비교 | 10 | 14,421 | 1,181 |

원본 기본 비교는 성공한 문항 묶음 18회와 Q08 연결 종료 시도의 1회를 포함한다. 기본 모드 문항별 시간은 4.07~7.87초, faithful은 2.05~2.77초다. 초기 custom-provider 연결 실험은 요청 옵션 오류로 HTTP 400이었고 사용량 미확인 1회다. 기본 OpenAI 연결 결과와 분리해 [실패 기록](initial-custom-transport-failure.json)에 보존했다. 이후 기본 비교 Q08에서 소켓이 닫혀 완료 문항을 보존한 채 Q08~Q09만 재개했다. 당시 네이티브 종료 원인을 확정할 증거는 없으며 코드 결함이나 모델 오류로 단정하지 않는다.

사용량은 원본 API의 문자 수가 아니라 복사본에서 관측한 제공자 응답 토큰 수다. 금액 환산은 하지 않았다. 같은 가상 표본의 제한된 관찰이며 전체 기능 순위나 고객 업무 적합성을 증명하지 않는다. 원본의 자동 인제스트·전체 Lint·전체 그래프 기능을 이 실행에서 평가한 것은 아니다. 회사용의 해당 기능 증거는 단계별 평가에 있다.

재현 도구: `scripts/run-reference-evaluation.mjs`, 추가 모드는 `--faithful`. 결과: [기본 답변과 이벤트](results.json), [모델 호출](model-calls.json). 기준 입력 재현은 [회사용 전후 비교](../final-16-fixed/README.md)를 참고한다.
