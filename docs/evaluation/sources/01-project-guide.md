# 가상 새봄시 관제 시범사업 안내

자료 ID: SAMPLE-01 / 버전: 1 / 도메인: 교통관제 업무 / 프로젝트: 가상 새봄시 관제 시범사업
이 문서는 개발 검증을 위해 만든 가상의 자료입니다. 실제 고객 지침이나 법적 기준이 아닙니다.

## 목적
이 사업은 가상 교차로 3곳에서 관제 화면의 정보 갱신을 점검하는 시범사업이다.

## 용어
ITS는 이 개발 표본에서 지능형 교통체계를 뜻한다. 관제 화면은 수집된 교통 정보를 담당자에게 보여 주는 화면이다.

## 점검 기준
정상 통신 상태에서는 관제 화면을 30초 간격으로 갱신한다.
통신이 끊긴 경우에는 마지막 수신 시각과 통신 중단 표시를 함께 보여 준다. 마지막 수신 값을 최신 값으로 표시하면 안 된다.
재연결 후 60초 안에 새 데이터 수신 여부를 확인한다. 통신 장애 중에는 30초 갱신 기준을 충족했다고 판정하지 않는다.

## 검수
가상 담당자는 교차로별 정상 통신과 통신 중단 상황을 각각 한 번 이상 확인한 뒤 결과를 남긴다.
이 자료에는 사업 예산, 계약상 지체상금, 실제 법적 의무에 관한 내용이 없다.
