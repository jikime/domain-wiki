# 선택 문장 질문·수정

완성된 질문 답변의 `[[문서명|표시 이름]]`과 상대 Markdown 링크는 현재 같은 도메인·프로젝트에서 공개된 위키로 연결한다. 찾지 못하거나 이름이 겹치는 위키 링크는 해당 도메인의 문서 검색으로 이어진다. 후속 질문에는 답변 본문만 보내며 브라우저의 링크 매핑은 입력으로 신뢰하지 않는다.

위키 상세 화면에서 본문의 문장을 드래그하면 **선택 문장 AI 도우미**가 열린다. 질문에는 같은 도메인·프로젝트 범위에서 검색한 현재 공개 위키를 최대 5개까지 참고하며, 답변의 `[1]` 출처를 누르면 인용 문맥과 문서 링크를 볼 수 있다. 질문은 이어서 할 수 있고, 최근 6개 질문과 각 답변의 마지막 6,000자를 문맥으로 사용한다. 모델의 입력 한도를 넘으면 오래된 질문·답변 쌍부터 제외한다. 선택 문장 자체는 임의로 잘라 보내지 않는다.

작성 화면에서는 **마크다운** 또는 **미리보기**에서 선택한 뒤 수정안을 만들 수 있다. 원본 위치가 정확히 연결되는 선택만 수정할 수 있다. 수정안을 직접 고치고 추가·삭제 표시를 확인한 후 **편집 중인 본문에 적용**을 누른다. 앞뒤 본문은 보존하며, 초안 저장 시 기존 버전·동료 검토 절차를 거친다. 질문과 수정 모드는 한 선택 안에서 처음 실행한 모드로 고정된다. 새 문장을 선택하거나 닫으면 대화가 초기화된다.

원본 `src/lib/selection-edit.ts`의 선택 위치 확인, CRLF 정규화, 완성된 바깥 Markdown 펜스만 제거하는 규칙, 한국어를 포함한 단어 단위 비교를 옮겼다. `WikiReader`의 줄 위치 기반 매핑을 사용하므로 같은 문장이 다른 블록에 반복되어도 선택한 블록을 확인한다. 원문 위치를 찾지 못한 렌더링 선택은 질문만 허용한다. 프롬프트는 원본의 앞뒤 1,200자 문맥과 지시문을 유지하며, 질문 온도 0.4·수정 온도 0.2로 채팅 모델에 요청한다.

선택 뒤 본문이나 최신 버전이 바뀌면 적용을 거절한다. 질문·생성 중 및 완료 시 회원 권한, 선택한 버전의 접근 권한, 참고 위키와 연결 원문의 현재 공개 상태를 확인한다. 후속 질문은 이전 응답 해시와 출처를 다시 확인한다. 생성 중지·화면 닫기·이동은 요청을 취소하고 미완성 결과를 적용할 수 없게 한다.

선택 문장과 대화 본문은 서버 생성 결과에 저장하지 않는다. 사용량·상태와 후속 질문 검증에 필요한 해시·출처 ID를 기록한다. 작업공간의 AI 동시 실행·사용량 정책을 적용하며, 요청 시간은 설정값과 120초 중 작은 값이다. 선택 길이는 40,000자까지, 편집 문서는 기존 본문 저장 한도를 따른다. 모델 출력은 검토할 제안이며 실제 모델의 문장 품질은 운영 모델 연결 후 확인해야 한다.
