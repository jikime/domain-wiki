# 위키 본문 Milkdown 편집기

2026-09-09 사용자 요청에 따라 위키 새 작성·새 변경안 작성 화면에 Milkdown **7.22.1**을 적용했다. 기본 화면은 서식 편집이며, 마크다운 직접 편집과 기존 게시 화면 기준의 미리보기를 함께 제공한다.

## 사용 흐름

- 제목 1~6·일반 본문, 굵게·기울임·취소선·인라인 코드, 글머리·번호·할 일 목록, 인용문·코드 블록·표·링크를 도구에서 선택한다. 실행 취소·다시 실행과 기본 키보드 편집도 지원한다.
- 표 안에서는 행·열 추가와 삭제, 표 삭제, 표 아래로 이동하는 도구가 나타난다. 열 너비 조절과 셀 사이 Tab 이동을 지원하며 넓은 표는 편집 영역 안에서 스크롤한다.
- 할 일 항목에 커서를 놓으면 공식 Checkbox로 완료 상태를 바꿀 수 있다. 링크는 표시 문구와 웹·메일·위키 주소를 입력해 삽입한다.
- 저장은 기존 마크다운 본문 API를 사용한다. 원문 근거 선택, 새 버전 생성, 작성자·검토자 분리, 승인·게시 흐름을 유지한다. 적용 대상은 위키 본문이며 다른 작성 폼의 입력 방식은 이번 요청에 포함하지 않았다.

## 본문과 초안 보존

기존 문서를 열거나 편집 방식만 바꾸면 원래 마크다운 문자열을 유지한다. 실제 서식 편집 시에는 Milkdown 직렬화 규칙에 따라 공백·목록 기호 등이 정리될 수 있으므로 정확한 원문 형식은 마크다운 모드에서 조정할 수 있다.

본문 트랜잭션을 동기적으로 마크다운에 반영한다. 기본 listener의 지연 알림에 저장을 의존하지 않아 입력 직후 저장·전환·이동에도 마지막 입력이 반영된다. 외부에서 복원한 초안·버리기는 별도로 문서를 교체하며 이전 내용이 다시 덮어쓰지 않게 한다. 도구의 메뉴가 닫힌 뒤 본문으로 포커스를 돌려준다. 전체 선택 후 방향키·Enter를 빠르게 누를 때 브라우저의 선택 변경 이벤트가 늦게 도착하는 현상도 재현해, 전체 선택 해제를 편집기 상태에 즉시 반영하도록 보완했다.

서버 저장 한도는 40,000자다. 서식 편집에 긴 내용을 붙여넣으면 자르지 않고 초과 안내와 저장 비활성화를 적용한다. 한도 안으로 줄이는 동안 200,000자까지 위키 임시 초안의 본문을 복원할 수 있다. 기존 같은 계정·같은 탭·24시간·전체 임시 보관 크기 제한을 함께 적용한다.

편집기는 위키 작성 화면에서만 별도 브라우저 청크로 불러온다. 로딩 또는 초기화 실패 시 마크다운 모드로 계속 작성할 수 있다. HTML은 실행하지 않고 텍스트로 다루며, 저장된 이미지 표기는 원문에 남기되 편집 화면에서는 대체 설명으로 표시하여 외부 이미지를 자동 요청하지 않는다. 게시 미리보기의 기존 HTML·이미지 제외 정책도 유지한다. 편집 중 링크 클릭은 페이지 이동으로 취급하지 않는다.

## 검증

- 편집기 전용 통합시험 4개가 7.3초에 통과했다. 서식·실행 취소·다시 실행, 제목 선택, 한글 조합 이벤트·마지막 입력의 실제 API 저장, 기존 표·코드·각주·부정문·이미지·HTML 원문 보존, 모바일 표·할 일·링크, 저장 실패·새로고침·초안 복원·버리기를 확인했다.
- 최종 변경으로 빌드·TypeScript 검사와 Biome 243개 파일 검사를 통과했다. 전체 통합시험 **119개가 4.6분에 통과**했다. 기존 권한·문서·검토·채팅·AI 중단 및 복구와 편집기 시험을 함께 실행한 결과다.
- 실제 개발 계정의 1440px·390px Chromium 화면에서 HTTP 200, 가로 넘침 0, 브라우저 오류 0, 외부 이미지 요청 0을 확인했다. [실화면 검사](browser-check.json), [데스크톱](editor-1440.png), [모바일](editor-390.png).
- OS의 실제 한글 입력기 전체 조합이나 Safari·Firefox 실기기는 이번 검사에 포함하지 않았다. 한글 문자 입력과 composition 이벤트를 Chromium 자동화에서 확인한 결과다.
