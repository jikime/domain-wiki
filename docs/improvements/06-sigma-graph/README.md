# 원본 Sigma 지식 그래프 화면 적용

큰 소개 영역, 상시 표시된 필터·위키 목록·군집·보완 설명을 그래프 중심 화면으로 교체했다. `llm_wiki/src/components/graph/graph-view.tsx`와 원본 `assets/3-knowledge_graph.jpg`를 대조했다.

## 화면 구성

- 상단: 작은 제목·실제 위키/연결 건수, 검색, 필터, 유형/군집 색상, 인사이트, 목록, 새로 확인.
- 중앙: 화면의 남은 높이를 사용하는 Sigma 그래프. 데스크톱과 모바일 모두 기본으로 표시한다. 큰 소개문과 페이지 하단의 분석 섹션은 제거했다.
- 오른쪽 위: 확대·축소·전체 보기. 캔버스의 마우스 드래그·휠·터치 이동과 확대는 Sigma가 처리한다.
- 왼쪽 아래: 유형/군집 범례. 유형별 표시 전환과 범례 접기를 제공한다.
- 필터: 버튼을 누를 때만 그래프 위에 연다. 도메인·프로젝트 범위, 위키 유형·최대 표시 수, 고립 위키, 최소/최대 연결 수, 노드 크기와 그래프 간격을 조정한다.
- 인사이트: 버튼을 누를 때만 오른쪽 패널을 연다. 관련 노드를 강조하고 연결된 위키로 이동한다.
- 위키 선택: 노드를 클릭하거나 접힌 목록에서 키보드로 선택한다. 게시 버전·원문 근거·관계·기존 검토 요청을 선택 패널에서 확인한다. 모바일에서는 패널이 그래프 위에 열린다.

## 원본과 동일한 라이브러리

원본에 설치된 버전과 동일하게 고정했다.

| 역할 | 라이브러리 | 버전 |
| --- | --- | --- |
| WebGL 그래프 표시 | sigma | 3.0.2 |
| React 연결 | @react-sigma/core | 5.0.6 |
| 노드 배치 | graphology-layout-forceatlas2 | 0.10.1 |
| 그래프 자료구조 | graphology | 0.26.0 |
| Louvain 군집 | graphology-communities-louvain | 2.0.2 |

직접 작성한 SVG 렌더러와 군집 원형/격자 배치는 제거했다. 원본의 노드 크기·유형/군집 색상, 이웃 강조, 카메라 조작 패턴을 적용했다. ForceAtlas2는 원본과 같은 가중 연결, 중력 1, 강한 중력, 50개 초과 Barnes–Hut 설정을 사용한다. 현재 상한 200개에서는 원본의 140회 반복을 적용한다. 초기 순서와 좌표를 고정해 입력 순서가 바뀌어도 같은 배치를 계산한다.

분석과 배치는 Web Worker에서 실행한다. 캐시는 입력 지문과 그래프 간격을 함께 확인한다. Next.js에서는 브라우저 전용 Sigma 컴포넌트를 `ssr: false`로 불러온다. 접근 권한·현재 게시 버전·원문 현행성·프로젝트 범위와 검색의 관계 점수는 기존 서버 검사를 유지한다.

원본은 Tauri 파일 프로젝트 앱이므로 앱 전체의 탐색 바와 파일 편집기를 복제하지 않는다. 현재 서비스의 상단 탐색과 직원 검토를 유지하고, 그래프 페이지의 라이브러리·배치·도구 모음·범례·필터·인사이트 구성을 적용했다. 원본에 없는 업무 위키 유형 `procedure`, `case`는 원본의 추가 색상 팔레트에 대응했다. 폼은 공식 shadcn 컴포넌트를 사용한다.

## 확인 결과

전체 통합시험 **199개**를 통과했다(10.8분). 패널 크기·키보드 보완 후 최종 생산 빌드를 다시 통과하고, 최종 코드의 그래프 전용 시험 **7개**를 재검증했다(11.4초). 타입 검사와 정적 검사도 통과했다. 전용 시험은 WebGL 캔버스의 실제 노드 클릭, 카메라 확대·복귀, 유형/군집 전환, 범례 숨김·필터 초기화, 고립 위키, 닫힌 인사이트, 모바일·키보드 선택, 원문/게시 버전 링크, 신고와 자료 범위, 권한 철회·취소·늦은 응답·캐시, 200개 분석을 확인한다.

실제 모델 평가에서 게시한 기존 가상 위키로 1440px/390px의 기본 화면·군집·필터·인사이트·선택 패널 10개를 확인했다. 모두 가로 넘침 0·브라우저 오류 0이며 WebGL 캔버스가 생성됐다. 이번 화면 검증은 모델을 호출하지 않았다. 패널의 크기 변경, 방향키 이동, 슬라이더 이름·키보드·간격 변경 후 포커스 유지, 우클릭 메뉴·숨김·초기화도 실제 브라우저에서 확인했다. [측정 결과](results.json), [추가 조작 확인](controls.json)
