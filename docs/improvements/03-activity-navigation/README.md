# 개선 3 — 내 활동·후속 행동·관리 검색

작성일: 2026-09-09. 기능 점검의 메뉴·연결 개선 항목을 구현했다.

## 사용 흐름

- 상단 계정 메뉴와 모바일 전체 메뉴에서 **내 활동**을 연다. 작성한 자료·위키·변경 묶음·RFP의 동료 검토 결과와 본인 신고·답변 의견의 처리 결과를 확인한다. 계정 메뉴에는 미확인 수를 표시한다.
- 결과별 또는 현재 페이지의 결과 전체를 확인 처리할 수 있다. 확인 상태는 계정별로 DB에 저장한다. 이후 다른 처리 이력이 생기면 새 미확인 결과가 된다. 알림은 페이지당 30건이며 다음 페이지와 미확인 필터를 제공한다.
- 내 활동에는 최근 작성·검토 대기 20건과 내 자료·위키 전체, 변경 묶음, RFP로 가는 링크가 있다. 검토 직원은 검토 대기 수와 내 담당 업무로 이동한다.
- 계정 메뉴·모바일 메뉴·업무 도구에서 프로젝트 목록을 바로 연다.
- 내 신고·답변 의견에서 의견을 남긴 **원래 답변**으로 돌아간다. 해당 답변에 초점을 맞추고 자동 최신 스크롤이 위치를 덮어쓰지 않도록 했다. 검토함의 의견에는 **처리하기** 링크를 두어 해당 항목만 바로 연다.
- 대화 관리에서 제목을 수정한다. 완료 답변은 출처 링크와 함께 복사한다. 클립보드 접근이 거절되면 현재 확인한 답변을 직접 선택해 복사할 수 있다.
- 자료실·위키의 검색 범위에서 **작성·검토 목록**을 선택하면 본인 작성 여부와 검토 대기·초안·반려 등의 상태로 검색한다. 공개 지식 검색은 기존 공개 범위를 유지한다. 도메인·다음 페이지 이동에도 검색 조건을 보존한다. 자료는 제목, 위키는 대표 버전의 제목·본문을 검색한다.

## 권한과 조회 경계

알림은 기존 검토·처리 이력을 본인 작성·제출 항목과 결합해 조회한다. 별도의 `activity_read` 테이블에는 읽은 결과의 식별자만 저장한다. 다른 직원이나 관리자가 타인의 결과를 확인 처리할 수 없다. 작성 역할이 없는 계정에는 비공개 작성 초안의 검토 결과를 제공하지 않는다.

원래 답변 링크는 본인 의견 API에서만 반환하며 대화의 소유자를 다시 확인한다. 검토 직원용 목록에는 개인 대화 ID나 본문을 추가하지 않았다. 답변 복사도 서버에서 현재 권한과 근거를 재검사하므로 화면을 연 뒤 근거가 철회되면 복사를 거절한다.

담당 업무와 특정 처리 항목은 DB 조회 제한 전에 필터링한다. 오래된 다른 요청 500건 뒤에 있는 내 담당 항목도 찾을 수 있다. 담당·오류 처리 목록은 선택한 범위에서 최대 500건이며 화면에 제한을 표시한다. 내 활동의 작성 목록은 최근 20건이며 전체 작성 목록 링크를 함께 제공한다. 개인 신고·답변 의견 상세의 기존 100건 제한은 이 단계에서 확장하지 않았다.

## 검증

- 프로덕션 빌드·TypeScript 및 Biome 214개 파일 통과.
- 전체 E2E **92개 통과**, 약 2.1분. 이후 담당 필터의 사전 적용을 추가하고, 신규 경계 시험을 포함한 관련 **18개 테스트**를 다시 실행해 모두 통과했다. 현재 등록된 전체 시험 수는 93개다.
- 신규 6개 시험: 70건 알림 페이징·읽음·새 결과, 계정 메뉴·모바일 프로젝트 이동, 원래 답변 위치·제목·복사·철회 차단, 검토 처리 링크와 개인 대화 비노출, 관리 검색·공개 검색·조건 유지, 다른 요청 501건 뒤의 내 담당 조회.
- 실제 개발 화면: 4개 역할, 1440px·390px의 **42개 화면 조합**에서 HTTP·JavaScript 오류와 문서 가로 넘침이 없었다. [측정 결과](browser-check.json).
- 화면 확인: [내 활동](activity-mobile.png), [자료 관리 검색](manage-sources-mobile.png), [위키 관리 검색](manage-wiki-mobile.png).

재실행: `npm run build && node scripts/test-integration.mjs`. 신규 범위와 기존 운영 흐름만 확인하려면 `node scripts/test-integration.mjs --grep '내 활동·후속 행동|6단계 개정'`을 사용한다.
