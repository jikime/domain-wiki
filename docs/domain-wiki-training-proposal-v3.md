# AI 스타터킷 기반 도메인 지식 서비스 교육 제안서

**작동하는 서비스를 이해하고, 회사 업무에 적용하며, 스스로 개선하는 7주 과정**

> 구현된 도메인 위키 스타터킷을 제공하고, 교육생이 구조와 사용 방법을 이해한 뒤 회사 자료와 업무 기준을 적용합니다. 필요한 지식을 찾아 AI와 함께 기능을 개선하고, 결과를 검증하는 과정을 반복합니다. 교육 이후에도 같은 코드와 지식 자산으로 프로젝트를 발전시키는 것이 목표입니다.

본 과정은 AI를 활용해 다양한 구현을 시도해 본 교육생을 대상으로 합니다. 기존 시도에서 막혔던 지점을 확인하고, 실제로 작동하는 서비스를 바탕으로 문제를 진단하고 해결하는 방법을 익힙니다.

### 교육을 통해 확보할 성과

- **서비스 이해:** 자료 등록부터 위키 생성·검토·검색·답변까지의 구조와 핵심 기술을 설명합니다.
- **업무 적용:** 회사 도메인의 자료·용어·지식 양식과 대표 업무 사례를 서비스에 반영합니다.
- **개선 역량:** AI와 공식 자료를 활용해 작은 변경을 수행하고, 변경 전후의 결과를 확인합니다.
- **개발의 연속성:** 코드·평가 자료·개선 기록과 다음 과제를 남겨 교육 이후의 개발로 연결합니다.

## 1. 제공 범위와 교육 방식

### 구현된 스타터킷 제공

도메인 위키의 기본 기능과 소스 코드를 제공하고, 교육생은 회사 업무에 맞는 적용과 개선에 참여합니다.

| 제공 기능 | 스타터킷에 구현된 내용 | 교육생의 적용·개선 |
| --- | --- | --- |
| 서비스 기반 | 로그인, 작업공간·도메인·프로젝트, 역할과 접근 권한 | 회사 업무 범위와 이용·작성·검토 역할 이해 |
| 자료 관리 | 원본·버전 보관, 문서 처리, 상태 확인과 재처리 | 대표 자료 등록, 추출 결과와 원문 비교 |
| 도메인 위키 | AI 초안, 근거 연결, 검토·게시·개정 | 회사 용어와 지식 양식 적용, 내용 검토 |
| 검색·채팅 | 키워드·의미 검색, 근거 기반 답변, 대화·출처 보관 | 실패 질문 진단, 검색 조건과 답변 결과 개선 |
| 업무 활용 | 실무 경험 기록, RFP 검토와 확인 질문 | 회사 사례와 요구사항에 적용, 검토 결과 보완 |
| 선택 활용 | 이미지 첨부, 웹 검색, 품질 점검과 관계 탐색 | 실습 과제와 연결 조건에 맞춰 활용 |

### 핵심 구조와 개발 방법 교육

화면·서버·데이터베이스·문서 처리 작업자·AI 모델이 연결되는 구조를 실제 기능과 함께 설명합니다. Next.js·TypeScript, PostgreSQL·pgvector 등의 역할과 API·환경변수·임베딩·RAG·버전 관리 같은 용어를 해당 실습에서 익힙니다.

강사는 기능의 위치를 찾고 수정하는 과정을 시연하고, 교육생은 안내에 따른 변경에서 시작해 자신의 과제를 직접 수행합니다. 구조 안내, 실습 가이드, 개발 요청 예시와 검증 기록 양식을 제공합니다.

### 회사 공용 AI와 선택형 웹 검색

서비스의 AI 기능은 회사의 지식 자산으로 구성원이 공동 활용할 수 있도록, **개인 구독 계정이 아닌 회사가 관리하는 API 요금제**로 구현합니다. API 키·사용량·비용은 회사 기준으로 관리합니다.

**Tavily 웹 검색은 선택 사항**이며 API 키가 필요합니다. 무료 제공량(크레딧) 초과 후 유료 요금제나 종량제를 이용하면 사용량에 따라 비용이 발생할 수 있습니다. 적용 조건은 [Tavily 공식 요금 안내](https://www.tavily.com/pricing)를 기준으로 확인합니다.

### 회사 도메인에 맞춘 개선 실습

첫 적용 분야는 ITS·교통관제 등 대표 자료와 검토 담당자를 확보할 수 있는 한 개 도메인으로 정합니다. 자료 5–10건과 평가 질문 10–15개를 출발점으로 삼고, 공통 실습 후 팀 개선 과제를 선정합니다.

개선 과제는 **약어·동의어 검색, 실무 경험 작성 양식, 위키 구성, RFP 검토 결과** 등을 후보로 검토합니다. 필요한 업무 지식은 공식 자료와 회사의 검토된 문서에서, 개발 지식은 현재 코드와 설치 버전에 맞는 공식 기술 문서에서 찾습니다.

**문제 재현 → 근거 탐색 → 변경 범위 정의 → AI와 수정 → 전후 비교 → 기록**의 순서로 실습하며, 과제의 난이도와 범위는 사전 진단과 교육 진행 상황에 맞춰 정합니다.

**교육 내용 조정 안내**

세부 교육 내용·순서·실습 비중은 교육생의 수준, 고객의 업무 요구, 자료와 실습 환경의 준비 상황에 따라 상호 협의하여 일부 조정할 수 있습니다. 핵심 교육 목표와 총 30시간은 유지하며, 추가 개발이나 교육시간 확대는 별도로 협의합니다.

교육은 **2026년 9월 17일(목)** 시작하며, 특별한 사정이 없으면 **매주 목요일 오후 2시부터 6시까지** 진행합니다. **교육 일정과 시간은 상호 협의하여 조정할 수 있습니다.** 마지막 7주차는 6시간 과정으로 진행 시간을 별도로 협의하며, 휴게시간 등 세부 운영도 함께 정합니다.

## 3. 산출물과 진행 조건

### 교육 종료 시 제공하는 결과

| 산출물 | 주요 내용 |
| --- | --- |
| 회사 도메인에 적용한 스타터킷 | 제공 소스 코드, 도메인 설정, 반영한 개선과 실행 안내 |
| 초기 지식·업무 적용 결과 | 대표 자료, 검토한 위키·실무 경험, RFP 요구사항 검토 사례 |
| 개선·검증 기록 | 과제별 변경 이유, 참고 근거, 전후 결과, 남은 문제 |
| 후속 개선 계획 | 우선순위, 담당자, 완료 기준과 다음 적용 범위 |

교육생은 합의한 작은 변경이나 오류 진단 과제를 수행하고, 무엇을 확인했는지 설명합니다. 최종 공유에서는 기능 시연과 함께 실제 업무에 도움이 된 점, 제한 사항, 다음 개선을 제시합니다.

### 진행 방식과 역할

| 구분 | 주요 역할 |
| --- | --- |
| 강사 | 교육용 스타터킷·실습 자료 준비, 사전 환경 점검, 개념 교육, 개발·오류 해결 코칭, 결과 리뷰 |
| 교육생 | 업무 문제 정의, 자료 적용, AI를 활용한 개선, 결과 검증과 기록 |
| 고객 담당자 | 자료·계정·참여 환경 준비, 업무 기준 검토, 최종 결과와 후속 추진 방향 확인 |

교육 전에는 교육생이 시도했던 사례와 실습 환경을 확인합니다. **4주차 중간 점검**에서 우선 개선 과제를 확정하고, **7주차 성과 공유**에서 결과와 다음 단계를 검토합니다. 최종 공유 시간에는 고객 실무 담당자의 참여를 권장합니다.

### 제공 및 협의 범위

- **기본 제공:** 총 30시간의 교육·코칭, 합의한 교육 준비, 스타터킷 소스와 학습 자료, 결과 리뷰 및 인계 안내.
- **고객 준비:** 승인된 대표 자료, 교육생 장비와 설치 권한, 코드 저장소, AI 개발 도구와 회사 AI API 계정·키. 웹 검색 선택 시 Tavily API 키.
- **별도 협의:** 합의한 과제 외 추가 구축, 운영 서버 배포, 교육 이후의 코칭·유지보수. AI 도구·API·실행 환경의 이용료는 교육비와 구분합니다.

핵심 실습과 평가는 교육시간 안에 편성하며, 준비된 예제 자료와 복구 지점을 활용해 실습을 이어갑니다. 실제 회사 자료의 검토와 운영 전환 조건은 고객 담당자와 확인합니다.

회사 자료와 교육 중 작성한 코드·평가 기록은 고객이 지정한 저장소와 계정에서 관리합니다. 스타터킷에 포함된 오픈소스의 라이선스와 저작권 고지를 함께 제공하며, 선행 개발 자산과 교육 결과물의 이용 범위는 계약에 명시합니다.

교육 후에도 같은 코드와 평가 자료를 사용해 개선을 이어갑니다. 실제 사용 중 발견한 문제를 다음 과제로 등록하고, 담당자와 확인 기준을 정해 프로젝트를 발전시킵니다.
