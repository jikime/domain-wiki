# [가상 교육 자료] 프로젝트 A · 상태 화면 검수 조건

문서 식별: A-ACCEPT-01 / 버전 1 / 프로젝트 A / 교육 예제 전용

## 승인된 검수 조건

프로젝트 A의 상태 화면 갱신 주기는 60초 이내로 한다. 이 값은 화면의 표시 갱신을 뜻하며 장애 복구 시간이나 현장 통신 지연을 뜻하지 않는다.

프로젝트 A의 상태 변경 이력은 90일간 보관한다.

## 확인 방법

교육용 표본 장비 3대를 골라 화면 표시 시각과 실제 갱신 시각을 비교한다. 확인한 장비, 시각, 기대 결과, 실제 결과를 기록한다. 표본 결과만으로 모든 장비의 성능을 보장하지 않는다.

## 해석 제한

이 조건에는 장애의 자동 복구 시간, 장비 교체 일정, 전체 사업의 성공률을 규정하지 않았다. ‘60초’라는 숫자가 들어 있다는 이유로 다른 성능 항목에 적용하지 않는다.
