# 공통 실습 자료 사용 안내

모두 **실습용 가상 자료**입니다. 실제 고객 사업이나 공식 지침이 아닙니다. 자료를 옮길 때도 제목과 본문의 가상 자료 표시를 남기세요.

## 시작할 환경 확인

배정된 주소에서 도메인 ‘가상 교통관제 자료’와 ‘프로젝트 A · 가람시’, ‘프로젝트 B · 누리시’를 찾습니다. 작업공간 이름은 환경마다 다를 수 있습니다. 초기 설치 예시인 ‘가상 새봄시 관제 시범사업’을 프로젝트 A로 간주하지 않습니다.

처음에는 샘플 자료와 게시 위키가 준비된 환경으로 업무를 해 봅니다. 내 개발 환경을 만든 뒤에는 같은 자료 상태인지 강사와 확인하세요. 기본 설치 명령만으로 교육용 A/B와 아래 자료가 모두 만들어지지는 않습니다.

이미 등록된 샘플은 다시 올리지 않습니다. 등록 실습에는 배정된 팀 연습용 자료를 사용하고, 가상 자료임을 밝힌 고유 제목을 붙입니다. 예를 들어 ‘[가상 실습·팀1] 안내판 점검 메모’처럼 샘플 사업의 확정 기준과 구분하세요.

## 원문과 근거 찾기

자료 번호 `01`, `03`, 질문 번호 `Q01`은 이름을 찾는 표시입니다. 앱이 만든 자료·버전·문단 ID와 다릅니다. 화면에 나온 실제 문단을 근거로 선택하세요. 줄 번호는 추출 방식에 따라 달라질 수 있으므로 자료 제목·버전·문장을 함께 봅니다.

공개 검색은 원문 문단과 게시 위키를 찾으므로 등록 문서 수보다 결과가 많을 수 있습니다. 캡처의 수량을 정답으로 맞추지 말고, 무엇을 세는지 확인합니다.

## 개선 전후를 비교할 때

같은 자료·계정·질문 범위·AI 연결로 비교합니다. 원문에 답이 없으면 확인할 질문으로 남기고, AI가 응답하지 않았다면 미확인으로 기록합니다. 기대 근거를 찾았는지는 직접 원문을 열어 판단합니다.

개정 실습에서 v2를 공개하면 갱신 기준은 60초에서 30초로 바뀌고 보관 90일은 유지됩니다. 자료 개정의 효과와 코드 개선의 효과는 따로 확인합니다.

## 회사 자료로 바꾸기

대표 업무에 필요한 자료 몇 건과 질문부터 고릅니다. 자료마다 사용 승인·적용 범위·현재 버전·검토 담당을 확인하세요. 가상 자료의 수치와 기관 이름을 회사 사실로 복사하지 않습니다. 스캔이나 큰 문서는 추출 결과를 먼저 확인합니다.
