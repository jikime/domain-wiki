# [가상 교육 자료] 프로젝트 A · 가람시 관제 자료 개선 사업 개요

문서 식별: A-OVERVIEW-01 / 버전 1 / 교육 예제 전용

## 사업 목적

프로젝트 A는 가람시의 관제 담당자가 장비 상태와 검토 이력을 한 화면에서 확인하도록 자료를 정리하는 가상 사업이다. 실습 대상 장비는 도로전광표지 24대이다.

## 포함 범위

장비 상태 화면, 상태 변경 이력 조회, 문서 검토 기록을 포함한다. 장비 상태 화면의 갱신 주기와 이력 보관 기간은 별도 검수 조건의 현재 승인본을 따른다.

## 제외 범위

현장 장비 교체와 장비 제어 명령의 자동 전송은 이 사업의 범위에 포함하지 않는다. 화면 조회 개선이 현장 장비 교체의 승인을 뜻하지 않는다.

## 사업별 적용

이 문서는 프로젝트 A에 적용한다. 다른 지역 사업의 수치나 요구사항을 프로젝트 A의 조건으로 사용하지 않는다. 최종 사업 종료일과 총사업비는 이 문서에 정하지 않았다.
