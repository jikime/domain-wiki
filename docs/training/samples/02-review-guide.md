# [가상 교육 자료] 관제 자료 공통 검토 절차

문서 식별: COMMON-REVIEW-01 / 버전 1 / 도메인 공통 / 실제 기관 지침 아님

## 검토 기록

가상 교육 프로젝트의 검토 기록에는 확인 항목, 확인 시각, 기대 결과, 실제 결과, 확인자를 남긴다. 수치를 비교할 때는 값과 단위, 측정 조건을 함께 적는다.

## 공개와 개정

작성자는 원문과 적용 범위를 확인하고 검토를 요청한다. 다른 검토자는 원문·근거·변경 내용을 확인한 뒤 공개 또는 수정 요청을 결정한다. 예전 검수 조건과 새 검수 조건이 다르면 현재 승인된 버전과 적용 시점을 확인한다.

## 경험과 기준

한 사업의 실무 경험은 다른 사업의 공식 의무가 아니다. 경험을 참고하려면 당시 상황과 대상, 적용 조건이 이번 업무와 맞는지 확인한다.

## 자료에 없는 내용

원문에 없는 수치·일정·원인은 확정된 사실로 쓰지 않는다. 필요한 확인 질문과 확인할 담당자를 남긴다.
