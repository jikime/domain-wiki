# [가상 교육 자료] 프로젝트 B · 누리시 상태 조회 조건

문서 식별: B-ACCEPT-01 / 버전 1 / 프로젝트 B / 교육 예제 전용

## 적용 범위

이 문서는 누리시의 가상 프로젝트 B에만 적용한다. 가람시 프로젝트 A의 조건을 변경하지 않는다.

## 승인된 조건

프로젝트 B의 도로전광표지는 12대이다. 상태 화면 갱신 주기는 120초 이내, 상태 변경 이력 보관 기간은 30일이다.

## 해석

같은 도메인에 있더라도 프로젝트 A와 B는 장비 수와 검수 조건이 다르다. 프로젝트 이름과 원문을 함께 확인한다.
