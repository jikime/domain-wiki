# [가상 교육 자료] 실무 경험 입력용 메모

이 파일은 ‘실무 기록’ 화면에 입력할 재료입니다. 파일을 별도 업로드해 같은 경험을 두 번 만들지 않습니다.

## 기록 제목

프로젝트 A 표본 점검에서 날짜 필터를 확인한 경험

## 작성 당시 메모

가상 점검 중 표본 3대의 조회 결과가 비어 보였다. 담당자와 화면 조건을 확인하니 조회 날짜가 이전 달로 지정되어 있었다. 현재 날짜로 바꾸자 자료가 표시되었다. 모든 조회 오류가 날짜 조건 때문이라는 뜻은 아니다. 같은 증상이면 범위와 권한도 먼저 확인하면 좋겠다.

## 상황

프로젝트 A의 표본 3대를 점검하던 중 상태 변경 이력 목록이 비어 보였다.

## 판단과 이유

자료 삭제를 단정하기 전에 조회 날짜와 프로젝트 범위를 확인했다. 화면에 선택된 날짜가 점검 대상 기간과 달랐다.

## 결과

조회 날짜를 점검 대상 기간으로 바꾸자 표본 3대의 이력이 표시되었다. 별도의 자료 복구나 코드 변경은 하지 않았다.

## 추가 확인할 내용

다음 사례에서도 날짜, 프로젝트 범위, 공개 상태와 권한을 확인한다. 이번 관찰만으로 모든 빈 검색 결과의 원인을 일반화하지 않는다.
