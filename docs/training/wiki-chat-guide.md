# 위키 작성부터 채팅까지

개발한 기능을 실제 자료로 확인할 때 참고합니다. 모든 조작은 위키 웹 화면에서 합니다. 작성자와 다른 검토자 계정을 준비하세요.

## 자료 등록과 공개

1. **자료실 → 새 자료 등록**에서 사용할 자료와 업무 범위를 선택합니다.
2. 처리 완료 뒤 추출한 내용을 원문과 비교합니다.
3. 다른 검토자가 **검토함**에서 원문과 공개 범위를 확인하고 공개합니다.

연습에는 [가상 프로젝트 A 사업 개요](samples/01-project-a.md)를 사용합니다. 회사 자료는 사용 승인을 받은 문서로 바꿉니다. 처리 완료와 공개 승인은 다릅니다.

## 위키 작성과 근거 연결

**위키 → + 위키 작성**에서 원문과 같은 도메인·프로젝트를 선택합니다. AI 초안을 만들었어도 아래 내용을 확인합니다.

```text
제목: [직원이 찾을 업무 주제]
범위: [업무·프로젝트]
확인된 내용과 예외: [원문에서 확인한 사실]
아직 확인할 질문: [내용·담당]
근거: [실제 자료·문단]
```

**공개 원문의 근거 선택 → 근거 검색**에서 해당 문단을 골라 **초안 저장**합니다. 게시 요청에는 공개 원문 근거가 필요합니다. 초안 상태는 아직 채팅 검색 대상이 아닙니다.

## 검토와 게시

작성자가 **검토와 게시 → 검토 요청**을 누릅니다. 다른 검토자는 **검토함 → 위키 게시 요청**에서 본문과 근거를 비교한 뒤 승인하거나 반려합니다. 반려되면 새 변경안을 작성해 다시 요청합니다.

본인이 작성한 버전은 다른 검토자가 승인합니다. 승인 후 공개 상태가 **게시**인지 확인합니다.

## 채팅에서 사용

게시된 위키의 **이 위키에 질문하기**를 엽니다. 위키를 함께 참고하려면 **원문만 사용을 끕니다.** 근거를 비교하는 연습에서는 웹 검색도 끕니다.

```text
프로젝트 A의 포함 업무와 제외 업무를 구분해 주세요.
도로전광표지 수량과 각 내용의 근거도 알려 주세요.
```

가상 A의 24대와 포함·제외 범위를 원문과 비교합니다. 인용 표시나 **참고 자료**를 열어 실제로 어떤 위키·원문을 썼는지 확인하세요. 답변이 나온 것만으로 특정 위키가 인용됐다고 판단하지 않습니다.

## 답변을 다시 위키로 남기기

작성 계정에서 완료된 답변 아래 **위키 초안으로 저장 → 저장한 위키 초안 열기**를 누릅니다. 답변과 참고 근거가 새 초안에 담깁니다. 내용·범위·근거를 확인하고 필요하면 검토를 요청합니다. 기존 위키와 중복되면 기존 글의 보완부터 검토합니다.

## 막히면 확인할 것

| 상황 | 확인할 곳 |
| --- | --- |
| 작성·저장 버튼이 없음 | 작성 역할, 답변 완료 여부 |
| 근거 검색·게시 요청이 안 됨 | 원문의 공개 상태, 범위, 선택한 근거 |
| 위키에 질문하기가 없음 | 게시 상태, 원문 개정·공개 철회 여부 |
| 답에 필요한 자료가 없음 | 도메인·프로젝트·원문만 사용 설정 |
| 답변 저장 시 범위 안내 | 범위를 하나로 좁히고 현재 자료로 다시 질문 |

결과는 별도 보고서 대신 개발 중인 작업 카드에 위키·질문·근거의 위치를 연결합니다.
