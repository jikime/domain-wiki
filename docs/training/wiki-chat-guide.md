# 실제 사용 따라 하기 · 직접 쓴 위키로 질문하기

**직접 쓴 위키도 검토를 거쳐 게시하면 채팅에서 참고할 수 있습니다.** 짧은 위키 한 개를 작성하고, 그 위키에서 채팅을 열어 답변이 어떤 근거를 참고했는지 확인합니다. 유용한 답변을 다시 위키 초안으로 남기는 방법도 함께 살펴봅니다.

모든 입력은 **브라우저의 도메인 위키 화면**에서 합니다. 실행부터 필요하다면 [다시 사용하는 방법](daily-use.md)을 먼저 보세요. 이 안내는 1단계 선택 활동과 3단계 위키 실습에서 참고하며, 별도 필수 과제를 추가하지 않습니다.

## 시작 전에 준비할 것

- **자료:** [프로젝트 A 사업 개요](samples/01-project-a.md)가 같은 교육용 도메인·프로젝트 A에 등록되어 처리와 공개가 끝나 있어야 합니다. 아직 준비되지 않았다면 [1단계 실습 C](weeks/01-experience.md#6-실습-c--자료-한-건으로-업무-흐름-확인하기)의 등록·공개 절차부터 진행합니다.
- **계정:** 작성 직원 계정과, 작성자와 다른 검토 직원 계정을 준비합니다. 채팅만 이용할 때는 이용 직원 계정으로도 가능합니다. 관리자라도 작성 역할이 없으면 위키 작성 버튼이 보이지 않을 수 있습니다.
- **예제 범위:** 아래 내용은 기존 교재의 가상 교육 사례입니다. 회사에서 사용할 때는 사용 가능한 실제 자료와 해당 프로젝트로 바꿉니다.

이미 같은 위키를 만들었다면 새로 만들지 말고 게시 상태를 확인한 뒤 4단계부터 이어갑니다.

## 1. 위키 화면에서 글을 작성합니다

작성 계정으로 로그인한 뒤 **위키 → + 위키 작성**을 누릅니다. ‘업무 도메인’과 ‘프로젝트’를 원문과 같게 선택하고 아래 예시를 입력합니다. 위키 유형은 처음에는 기본값을 사용하고, 별칭은 비워 두어도 됩니다.

**위키 제목:** `[가상 교육 자료] 프로젝트 A의 사업 범위`

**본문에 입력할 예시:**

```text
포함 범위
프로젝트 A는 도로전광표지 24대를 대상으로 장비 상태 화면,
상태 변경 이력 조회, 문서 검토 기록을 정리한다.

제외 범위
현장 장비 교체와 장비 제어 명령의 자동 전송은 포함하지 않는다.

확인할 사항
최종 사업 종료일과 총사업비는 사업 개요에 정해져 있지 않다.
```

**확인할 결과:** 제목·본문과 프로젝트 A가 입력되어 있습니다. 문장을 그대로 외우기보다 원문의 포함·제외 범위가 유지되는지 확인합니다.

## 2. 원문 근거를 연결하고 초안을 저장합니다

같은 작성 화면 아래의 **공개 원문의 근거 선택**에서 ‘가람시’ 또는 ‘사업 개요’를 입력하고 **근거 검색**을 누릅니다. 결과의 문단을 읽고 위 본문의 수량·포함 범위·제외 범위·확인할 사항을 뒷받침하는 문단에 체크합니다. 내용이 여러 문단으로 나뉘어 있으면 필요한 문단을 각각 선택합니다.

**초안 저장**을 누른 뒤 저장된 위키에서 본문과 ‘연결한 원문 근거’를 확인합니다. 게시 요청에는 공개 원문 근거가 한 개 이상 필요하며, 단순히 개수를 채우기보다 작성한 내용에 맞는 근거를 골라야 합니다.

**확인할 결과:** 위키가 ‘초안’으로 저장됩니다. 이 상태에서는 아직 채팅의 검색 대상이 아닙니다. 공개 근거가 보이지 않으면 원문의 공개 상태와 선택한 도메인·프로젝트부터 확인합니다.

## 3. 검토를 요청하고 게시합니다

1. 작성자는 위키 상세 화면의 **검토와 게시 → 검토 요청**을 누릅니다.
2. 다른 검토 계정으로 로그인해 **검토함 → 위키 게시 요청**에서 해당 제목을 엽니다.
3. 본문과 연결한 원문을 비교합니다. 내용이 맞으면 **위키 게시 승인**을 누릅니다. 수정이 필요하면 검토 의견을 적고 **반려**합니다. 작성자는 ‘새 변경안 작성’에서 고친 뒤 다시 검토를 요청합니다.

**확인할 결과:** 승인된 위키의 공개 상태가 **게시**로 표시됩니다. 본인이 작성한 버전은 다른 검토자가 승인해야 합니다.

## 4. 게시된 위키에서 채팅을 엽니다

작성 계정으로 돌아와 게시된 위키를 열고 **이 위키에 질문하기**를 누릅니다. 채팅에 해당 위키와 도메인·프로젝트 범위가 연결됩니다. 위키와 연결된 원문을 함께 참고하도록 **원문만 사용은 끄고**, 이번 연습에서는 웹 검색도 끕니다.

채팅 입력창에 아래처럼 질문합니다.

> 프로젝트 A에서 포함하는 업무와 제외하는 업무를 나누어 정리해 주세요. 도로전광표지 수량도 알려 주고, 참고한 근거를 표시해 주세요.

**확인할 결과:** 답변에서 ‘24대’, 포함 업무 세 가지, ‘현장 장비 교체·장비 제어 명령 자동 전송 제외’를 원문과 비교할 수 있습니다. 이어서 ‘최종 사업 종료일은 언제인가요?’라고 물으면 자료에서 확인할 수 없는 날짜를 임의로 정하지 않는지 봅니다.

평소에는 **채팅** 메뉴에서 도메인과 프로젝트를 선택해 질문해도 됩니다. 이 경우 범위 안의 게시된 위키와 공개 원문을 함께 찾습니다. 특정 위키로 시작하고 싶을 때는 위의 ‘이 위키에 질문하기’가 편리합니다.

## 5. 답변이 참고한 근거를 확인합니다

답변의 인용 표시나 **참고 자료**를 눌러 문서 제목과 내용을 확인합니다. 직접 쓴 위키가 인용되었는지, 사업 개요 원문이 인용되었는지 구분해 보세요. 위키에서 채팅을 열어도 관련 원문이 함께 사용될 수 있어, 답변이 나온 것만으로 위키를 인용했다고 판단하지 않습니다.

**확인할 결과:** 수량과 포함·제외 범위를 뒷받침하는 실제 근거를 열 수 있습니다. 답변에 없는 조건이 붙거나 수치가 다르면 그 부분을 짚어 다시 질문하고, 원문과 맞는지 확인합니다.

## 6. 유용한 답변을 위키 초안으로 남깁니다

다시 참고할 만한 답변이라면 작성 계정에서 답변 아래의 **위키 초안으로 저장**을 누르고, 이어서 **저장한 위키 초안 열기**를 누릅니다. 해당 답변과 참고 근거가 새 위키 초안에 담깁니다. 질문이나 대화 전체를 저장하는 기능은 아닙니다.

제목을 알아보기 쉽게 다듬고 본문·범위·근거를 확인한 뒤 **초안 저장**을 누릅니다. 동료에게 공유할 내용이면 3단계와 같이 검토를 요청합니다. 기존 위키와 같은 내용이라면 새 초안을 바로 게시하기보다 기존 위키를 보완할 필요가 있는지 먼저 살펴봅니다.

**확인할 결과:** 저장한 답변을 위키 초안으로 다시 열 수 있습니다. 이 실습에서는 초안 저장까지 확인해도 충분합니다. 새 초안 역시 승인·게시된 뒤에 채팅에서 활용됩니다.

## 막히면 여기부터 확인하세요

| 보이는 상황 | 먼저 확인할 것 |
| --- | --- |
| 위키 작성·답변 저장 버튼이 없음 | 현재 계정에 작성 역할이 있는지 확인합니다. 답변 저장은 응답이 완료된 뒤 가능합니다. |
| 근거가 없거나 게시 요청을 할 수 없음 | 같은 도메인·프로젝트의 공개 원문을 찾아 근거 문단을 선택했는지 확인합니다. |
| ‘이 위키에 질문하기’가 보이지 않음 | 현재 게시본인지, 연결한 원문이 개정되거나 공개 철회되지 않았는지 확인합니다. |
| 질문에 필요한 자료를 찾지 못함 | 선택한 도메인·프로젝트·위키와 ‘원문만 사용’ 설정, 자료의 공개 상태를 확인합니다. |
| 답변을 위키로 저장할 때 범위 안내가 나옴 | 도메인과 프로젝트를 하나로 좁혀 다시 질문합니다. 근거가 개정·철회되었다는 안내라면 현재 자료로 다시 질문합니다. |

마지막으로 **작성한 위키 주소, 질문 한 개, 확인한 근거, 저장한 초안 주소**를 짧게 남기세요. 다음에 같은 업무를 할 때 그 위치에서 이어갈 수 있습니다.
