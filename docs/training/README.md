# 함께 개발하는 우리 회사 위키

스타터킷을 회사 업무에 맞게 바꾸고 사내에서 계속 쓸 위키를 만듭니다. 실제 화면에서 불편을 찾고, 계획을 확인한 뒤 강사의 코칭을 받으며 AI와 구현하고, 직접 사용해 결과를 판단합니다. 같은 코드와 자료를 이어서 발전시킵니다.

## 세 자료의 역할

| 구분 | 쓰는 방법 |
| --- | --- |
| [강의 화면](/lectures/index.html) | 실제 화면·바꿀 목표·계획과 실행 요청을 함께 봅니다. |
| 워크북 | 작업 중 필요한 순서·요청문·완료 기준을 찾습니다. |
| 강사 코칭 | 막힌 화면을 함께 보고 개발 범위와 구현 방향을 조정합니다. |

워크북을 처음부터 모두 읽을 필요는 없습니다. 강의에서 연결한 실습을 열고 직접 작업하세요. 설치와 상세 사용법은 필요할 때 찾아봅니다.

개인 PC에서는 [첫 실행](getting-started.md) 뒤 [교육용 샘플](sample-data.md)을 준비합니다. 저장소에 포함된 백업 파일로 자료와 게시 위키를 넣어 같은 화면에서 실습을 시작합니다.

## 같은 위키를 이어 만드는 순서

| 실습 | 남길 결과 |
| --- | --- |
| [실행하고 개발할 곳 찾기](weeks/01-experience.md) | 자료·위키·질문의 근거 확인 / 계획을 확인하고 직접 바꾼 첫 화면 |
| [우리 업무에 필요한 자료를 모아 쓰는 위키 만들기](weeks/02-architecture.md) | 저장한 조건으로 다시 검색하기 / 홈의 폴더·안 읽은 개수·원문 연결 |
| [회사 경험을 기록하고 다시 찾는 위키 만들기](weeks/03-domain.md) | 작성 모달·유형별 안내 / 여러 개인 DB 초안 / 근거와 검토 요청 / 내 확인할 일 / 교시별 업무 적용 |
| [자료를 회사 업무 위키로 정리하기](weeks/04-evaluation.md) | 자료별 검색 / 업무 절차 작성 도움 / 위치별 수정 의견과 게시 / 원문 개정과 위키 보완 |
| [채팅과 지식 그래프로 근거 확인하기](weeks/05-development.md) | 질문과 범위 저장 / 개인 답변 확인 기록 / 두 위키 비교·복귀 / 코드와 DB를 함께 반영한 첫 통합본 |
| [업무 결과물과 회사 설정 관리하기](weeks/06-debugging.md) | RFP 항목 확인·질문 답변 / 용어 편집·메뉴별 이용 안내 / 추가 통합과 역할별 확인 |
| [통합 위키로 업무를 확인하고 운영 인계하기](weeks/07-application.md) | 인수인계 준비 기록 / 메모 저장 안정화 / 자료 갱신·운영 점검 / 최종 버전·담당·남은 과제 |

첫 작은 변경에서 계획 확인 방법을 익힙니다. 검색·즐겨찾기·메모를 DB에 연결하고, 회사 기록과 검색 기능을 발전시킵니다. 각자의 결과를 코드와 DB 변경까지 함께 검토해 통합하고 실제 운영으로 이어갑니다. 기본을 마친 뒤 선택 과제를 고릅니다.

## 기록은 한 곳에

[회사 개발 노트](company-project.md)에 목표, 작업 카드, 운영 인계를 모읍니다. 코드·화면·AI 대화의 위치를 연결하고 직접 확인한 결과와 다음 행동만 짧게 남기세요.

## 회사 도입을 함께 준비합니다

공용 환경과 담당자는 첫 화면 변경 때 정합니다. 검증한 코드와 DB 변경을 통합 개발 환경에 적용합니다. 공용 환경은 담당 절차로 반영하고 준비된 주소에서 역할별 계정으로 직접 확인한 뒤 운영 인계로 이어 갑니다. 개인 PC 실행과 실제 회사 도입은 각각 확인하며, 미완료 항목은 담당자와 다음 조치를 정합니다.
