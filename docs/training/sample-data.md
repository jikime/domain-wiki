# 교육용 샘플 넣기

스타터킷을 설치한 뒤 **일반 터미널**에서 샘플을 한 번 넣습니다. 회사 자료를 준비하지 않아도 같은 사업 개요·검수 조건·위키를 보며 실습할 수 있습니다.

## 1. 처음 설치했다면

[위키 받기와 첫 실행](getting-started.md)의 계정 준비까지 마친 뒤, 프로젝트 폴더에서 실행하세요. DB는 켜져 있어야 합니다.

```bash
npm run db:seed-training
npm run db:check-training
```

첫 명령은 저장소에 포함된 샘플 백업을 DB에 넣고 원본 파일을 준비합니다. 두 번째 명령은 자료 수·공개 상태·위키 근거·원본 파일을 확인합니다. 웹 서버나 작업자, AI 연결 없이 준비할 수 있습니다.

완료 메시지에 **프로젝트 2개 · 자료 6건 · 문단 53개 · 게시 위키 2건**이 나오면 앱을 실행합니다.

```bash
npm run dev:all
```

## 2. 화면에서 확인하기

1. [위키](http://localhost:3010)에 본인 PC의 계정으로 로그인합니다. 계정 정보는 `.local/initial-accounts.json`과 `.local/content-accounts.json`에 있습니다. 샘플을 넣어도 비밀번호는 바뀌지 않습니다.
2. 홈에서 **가상 교통관제 자료** 도메인을 고릅니다. 처음 설치할 때 생기는 ‘교통관제 업무 (개발 예시)’와는 다릅니다.
3. **자료 모아보기**를 열고 ‘공개 지식 검색’에서 **프로젝트 A · 가람시**를 선택합니다.
4. **검수**를 검색해 ‘프로젝트 A · 상태 화면 검수 조건’ 원문을 엽니다. 이어 **사업**을 검색해 ‘가람시 관제 자료 개선 사업 개요’도 엽니다.
5. **위키 둘러보기**에서 ‘프로젝트 A의 범위와 검수 기준’을 열고 연결된 원문 근거를 확인합니다.

검색 결과는 문단별로 표시될 수 있어 자료 6건보다 많을 수 있습니다. 채팅의 AI 답변은 모델 연결이 필요하므로 [AI 연결 안내](../MODEL_TRANSPORTS.md)에 따라 별도로 확인하세요.

## 3. 무엇이 들어 있나요

| 구분 | 준비되는 내용 |
| --- | --- |
| 도메인 | 가상 교통관제 자료 · 목적·용어·작성 안내 |
| 프로젝트 | A · 가람시, B · 누리시 |
| 공개 자료 | 사업 개요·공통 검토 절차·검수 조건 v1·협의 메모·B 사업 조건·실무 기록 |
| 게시 위키 | 프로젝트 A의 범위와 검수 기준 / 검토 기록에 남길 내용 |
| 원본과 근거 | 자료 원본 6개, 검색 문단 53개, 위키와 원문 연결 |

검수 조건 v2와 신규 요청 문서는 이후 실습에서 직접 등록합니다. 즐겨찾기·메모 등 수업에서 개발할 기능은 이 샘플에 포함하지 않습니다.

샘플은 **가상 자료의 공개·게시 상태를 복사해 준비**합니다. 이번에 사람이 새로 승인했다는 뜻은 아니며 가져오기 기록을 따로 남깁니다. 직접 올리는 연습 자료와 회사 자료는 기존 등록·추출·검토·공개 절차를 따릅니다.

## 4. 다시 실행하거나 자료가 안 보일 때

- **‘이미 있습니다’가 나오면:** 기존 자료와 실습 결과를 유지한 것입니다. 같은 도메인을 중복 생성하거나 덮어쓰지 않습니다. `npm run db:check-training`으로 상태를 확인하세요.
- **초기 계정이 없다고 나오면:** [첫 실행](getting-started.md)의 `db:bootstrap`, `db:content-team`을 먼저 진행합니다.
- **검색이 0건이면:** 도메인과 프로젝트가 위 이름인지 먼저 확인합니다. 샘플 준비 오류가 있었다면 그 오류부터 강사와 확인하세요.
- **원본 파일이 없거나 기본 수와 다르면:** 기존 자료를 삭제하지 말고 강사에게 보여 주세요. 이미 실습 중 수정한 환경은 기본 샘플과 다를 수 있습니다. 준비 명령은 이를 자동으로 초기화하지 않습니다.

## 5. 백업 파일은 어디에 있나요

교육용 복구 파일은 저장소의 `docs/training/samples/training-snapshot.json`입니다. DB에 넣을 자료·문단·위키·근거와 원본 파일 내용이 한 파일에 들어 있습니다. [샘플 백업 파일 내려받기](samples/training-snapshot.json)도 가능합니다.

이 파일은 `db:seed-training` 명령으로 읽습니다. 앱의 자료 업로드나 프로젝트 ZIP 가져오기에 넣는 파일은 아닙니다. 소스와 함께 받은 경우 따로 내려받을 필요가 없습니다.

새 PC나 새로 설치한 빈 실습 환경에서는 계정을 준비한 뒤 같은 명령으로 샘플을 다시 넣습니다. 강사에게 별도 샘플 백업을 받았다면 경로를 지정할 수 있습니다.

```bash
npm run db:seed-training -- "받은파일경로/샘플백업.json"
```

**이 파일은 교육 시작 상태를 준비하는 용도입니다.** 계정·비밀번호·채팅·개인 실습 변경·회사 자료는 보관하지 않습니다. 작업한 위키 전체를 보존하려면 DB와 업로드 원본을 함께 백업해야 합니다. 회사 운영 백업은 [회사 적용과 운영](operations.md)에서 구분해 확인합니다.
