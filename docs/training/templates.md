# 필요한 기록만 골라 쓰기

기본 기록은 [회사 개발 노트](company-project.md) 하나면 됩니다. 아래 항목은 세부 정보가 필요할 때만 추가합니다. 기존 T 양식을 쓰고 있다면 같은 노트의 위치를 연결하세요.

## T0. 내 PC 업무환경 기록표

프로젝트 폴더 / 접속 주소 / 계정 역할 / 개발용 AI 응답 / 웹·자료 처리·서비스 AI 확인 / 미완료와 도움받을 사람. 비밀번호는 적지 않습니다.

## T1. 업무 문제 카드

사용자 / 업무 / 실제 불편 / 완성할 모습. 회사 개발 노트의 목표에 적습니다.

## T2. 업무 동작과 기술·구조의 연결

입력한 화면 / 서버가 확인할 조건 / 저장할 결과 / AI가 알려 준 파일 위치. 파일명을 외우지 않아도 됩니다.

## T3. AI 개발 요청

현재 입력·결과 / 기대 동작 / 유지할 조건 / AI 계획과 내 판단. [요청 예시](prompt-practice.md)를 참고해 작업 카드에 연결합니다.

## T4. 업무 근거·AI 설명 확인

질문 / 자료·버전·문단 / 확정 조건 / 아직 확인할 내용.

## T5. 변경 전후 비교

| 입력·조작 | 기대 결과 | 변경 전 | 변경 후 | 확인한 사람 |
| --- | --- | --- | --- | --- |
| 정상 입력 | | | | |
| 빈 값·삭제 등 필요한 조건 | | | | |
| 저장·다시 열기·기존 동작 | | | | |

## T6. 오류 진단

화면·역할 / 재현 순서 / 기대·실제 결과 / 확인된 원인 / 수정 / 같은 입력으로 재확인. 실패한 작업 카드에 이어 적습니다.

## T7. 평가 결과표

대표 업무·질문 / 근거가 맞는가 / 결과가 맞는가 / 보완할 곳 / 다시 확인한 결과.

## T8. 후속 개발 과제

직원의 불편 / 우선순위 / 담당 / 완료 기준. 회사 개발 노트의 다음 개발 목록을 사용합니다.

## T9. 인계 카드

공용 주소 / 코드 버전 / DB·원본·설정 관리 위치 / 자료·시스템·AI 담당 / 운영 안내 / 실제 사용·복원 확인 / 남은 조건과 담당. [회사 적용과 운영](operations.md)을 함께 확인합니다.
