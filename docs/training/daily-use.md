# 다시 사용하는 방법

설치와 로그인을 마쳤다면 이 안내를 따라 수업에서 기록한 환경으로 다시 접속합니다. 아직 첫 설치를 마치지 않았다면 [환경 준비](environment-setup.md)를 강사와 이어서 진행합니다.

교재를 웹으로 보려면 [http://localhost:3010/workbook](http://localhost:3010/workbook)을 엽니다. 공용 서버에서는 접속 주소 뒤에 `/workbook`을 붙이면 됩니다. 워크북 열람에는 로그인이 필요하지 않으며, 실제 자료 등록과 채팅은 위키 서비스에 로그인해 진행합니다.

## 먼저 내 환경을 고르세요

| 수업 때 사용한 환경 | 시작할 곳 |
| --- | --- |
| 회사의 공용 위키나 강사가 준비한 원격 접속 주소 | [T0 기록표](templates.md#t0-내-pc-업무환경-기록표)의 주소를 브라우저에서 엽니다. 서버 실행은 담당자가 안내한 방법을 따릅니다. |
| 내 PC에서 실행한 위키 | 아래 순서로 같은 프로젝트를 엽니다. |

공용 위키에 자료를 등록하고 질문하는 데에는 내 PC의 개발 서버를 새로 켤 필요가 없습니다. 코드 개선 실습은 강사가 지정한 개발 환경에서 진행합니다.

## 내 PC에서 다시 켜기

1. VS Code에서 **지난번 사용한 프로젝트 폴더**를 엽니다. 폴더 위치는 T0를 확인합니다. 새로 소스를 받거나 처음 설정을 반복하지 않습니다.
2. 일반 터미널을 엽니다. Windows는 Git Bash, macOS는 Terminal 또는 VS Code의 터미널입니다. 아래 명령으로 현재 폴더를 확인합니다.

```bash
pwd
```

출력이 T0의 프로젝트 경로와 같고 그 폴더 안에 `package.json`, `src`, `docs`가 보이면 이어갑니다. 경로가 다르면 강사에게 확인하고 이동합니다.

3. 기존 로컬 실습의 Docker Desktop을 켠 뒤, 같은 프로젝트의 일반 터미널에서 다음 명령을 실행합니다.

```bash
npm run dev:all
```

이 명령은 DB 준비가 끝난 뒤 웹 서버와 문서 작업자를 함께 실행합니다. 실행 중에는 이 창을 켜 둡니다. 이미 같은 위키가 실행 중이면 추가로 실행하지 않습니다. ‘주소가 이미 사용 중’이라는 안내가 나오면 포트를 바꾸기 전에 기존 실행 상태를 확인합니다.

4. 웹 서버와 작업자의 준비 로그를 확인하고 브라우저에서 T0에 적은 주소를 엽니다. 기본 로컬 주소는 `http://localhost:3010`입니다. 교육용 계정으로 로그인하고 같은 작업공간·도메인·프로젝트를 선택합니다.

**정상 결과 예시:** 지난번 저장한 자료나 위키를 다시 열 수 있습니다. 자료가 안 보이면 새 환경을 만들기 전에 로그인 계정·작업공간·프로젝트가 같은지 확인합니다.

웹 서버와 작업자를 따로 실행하는 방법은 [첫 실행 안내](getting-started.md#3-앱-실행)에 있습니다. `dev:all`은 첫 설치·마이그레이션·계정 준비를 마친 환경에서 사용하며, 초기 설정을 대신하지 않습니다.

## 할 일 시작하기

| 하려는 일 | 진행 방법 | 마친 뒤 확인 |
| --- | --- | --- |
| 기존 자료에 질문 | 위키 채팅에서 사용할 프로젝트를 선택하고 질문 | 근거를 열어 원문과 비교 |
| 위키를 직접 작성해 활용 | [실제 사용 따라 하기](wiki-chat-guide.md)에 따라 작성·근거 연결·검토·게시 | 게시된 위키의 ‘이 위키에 질문하기’로 답변과 근거 확인 |
| 유용한 채팅 답변 보관 | 작성 계정에서 완료된 답변의 ‘위키 초안으로 저장’ 선택 | ‘저장한 위키 초안 열기’에서 내용·근거 확인, 공유할 때 검토 요청 |
| 새 자료 추가 | 자료실에서 범위를 확인하고 새 자료 등록 | 처리 상태 확인 후 검토·공개 절차 진행 |
| 기존 자료의 개정본 반영 | 기존 자료를 열고 새 버전 등록 절차 사용 | 같은 자료의 버전과 변경 내용 확인 |
| 작은 기능 개선 | 별도의 터미널을 같은 프로젝트에서 열어 `claude` 실행 후 한국어로 요청 | AI의 계획 확인, 변경 후 실제 화면 확인 |

새 버전이나 위키 초안은 저장만 했다고 바로 공개되는 것은 아닙니다. 해당 역할과 검토 절차를 따릅니다. 위키·원문에 관한 질문은 위키 채팅에, 코드 변경 요청은 개발용 AI에 입력합니다.

## 마칠 때와 막혔을 때

입력 중인 내용은 저장하고, 다시 열어 확인합니다. 이번에 바꾼 내용과 다음에 할 일을 짧게 남기면 다음 수업에서 이어가기 쉽습니다.

개인 PC의 웹 서버·작업자를 종료하려면 진행 중인 처리가 끝났는지 확인한 뒤 `npm run dev:all`을 실행한 창에서 `Ctrl+C`를 누릅니다. 함께 실행한 웹 서버와 작업자는 종료되고 DB는 켜 둡니다. 각각 실행했다면 각 실행 터미널에서 종료합니다. 공용·원격 서버는 담당자의 안내를 따릅니다. 프로그램을 종료하는 것과 데이터를 삭제하는 것은 다르며, 자료를 보관하려고 DB를 초기화할 필요는 없습니다.

실행이나 로그인이 막히면 [도움 요청 틀](start-here.md#결과가-다르면-이렇게-도움을-요청하세요)에 교재 단계와 실제 결과를 적습니다. 비밀번호는 기록 대신 수업에서 안내받은 계정 관리 방법으로 확인합니다.
