# [가상 교육 자료] 프로젝트 A · 후속 단계 요청 문서

문서 식별: A-RFP-02 / 버전 1 / 7단계 신규 적용 실습용 / 실제 발주 문서 아님

## 요청 목적

프로젝트 A의 상태 조회 화면을 후속 단계 업무에 활용하기 위한 요구를 검토한다. 과거 사업 자료는 참고 사례이며 이 문서의 명시 요구를 대신하지 않는다.

## 명시 요구

R1. 후속 단계 상태 화면 갱신 주기는 45초 이내로 한다.

R2. 후속 단계 상태 변경 이력은 180일간 보관한다.

R3. 검토 기록에는 확인 항목, 확인 시각, 기대 결과, 실제 결과, 확인자를 포함한다.

R4. 현장 장비 교체와 장비 제어 명령 자동 전송은 이번 요청의 범위에서 제외한다.

## 협의가 필요한 범위

R5. 외부 기관과 필요한 자료를 연계할 수 있어야 한다. 대상 기관, 자료 항목, 연계 주기, 책임 주체는 이 문서에 정하지 않았다.

R6. 기존 운영에 지장이 없도록 전환해야 한다. 구체적인 허용 중단 시간과 전환 확인 방법은 이 문서에 정하지 않았다.

## 참고 시 유의점

기존 프로젝트 A의 화면 갱신 조건이나 보관 기간이 후속 단계 요구를 이미 충족한다는 사실을 이 문서가 보장하지 않는다. 적용 대상과 측정 조건을 비교하고 필요한 추가 작업을 확인한다.
