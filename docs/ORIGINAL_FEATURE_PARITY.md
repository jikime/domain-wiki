# llm_wiki 원본 기능 복원

2026-09-10 사용자 요청에 따라 아래 범위의 원본 기능을 웹 환경에 복원했다. 대상은 `my-domain-wiki`, 읽기 전용 참조는 `/Users/jikime/Dev/Private/Experimental/llm_wiki`이다. 후속 재점검에서 확인한 누락 중 3개를 구현했고, 브라우저 웹 클리퍼와 MCP 외부 연결은 후속 사용자 요청에 따라 제거했다. 아래에 최종 범위와 연결 상태를 명시한다. 원본 전체 기능의 완전한 동등성을 선언하지 않는다. 이전 단계의 완료·테스트 기록은 당시 구현에 대한 기록이다.

사용자가 지정한 Next.js, PostgreSQL, hince 스타일, 회사별 권한·근거·검토 및 RFP 기능을 유지한다. 원본의 순수 함수·프롬프트·알고리즘을 우선 옮기며 Tauri 파일·IPC 의존성은 웹 API와 권한이 적용된 DB·파일 저장으로 연결한다. 원본 자료와 사용자가 작성한 기존 콘텐츠를 변경하거나 삭제하지 않는다.

누락 기능 구현 이전 검증: 새 의존성 설치에서 **전체 통합 253개(기존 199개·복원 54개, 13.0분), 원본 함수 192개, 네이티브 변환기 8개**를 통과했다. 당시 통합시험의 실패·건너뜀은 0개다. 호스트·Linux 운영 빌드, 실제 모델 최초/개정, 별도 환경의 백업 복원을 완료했다. [당시 검증 요약](evaluation/core/original-parity-deployment/validation-summary.json)을 보존하며, 이후 변경의 검사는 [누락 기능 단계별 기록](MISSING_FEATURE_STAGES.md)에 따로 기록한다.

후속 사용자 지시에 따라 Docker 작업은 별도 요청이 있을 때만 수행한다. 현재 유지하는 3개 기능의 구현과 변경에 필요한 집중 검사를 완료했다. [단계별 구현 기록](MISSING_FEATURE_STAGES.md)에 사용 흐름·검사 범위·제외 항목을 구분한다. 개발 작업공간의 [Tavily 실제 연결](evaluation/tavily-connection-20260910/README.md)은 완료했다. 브라우저 확장 설치와 외부 AI 도구의 MCP 등록은 더 이상 진행할 항목이 아니다.

## 변경·검증 기록

- 착수: 원본과 현재 채팅·검색·병합·문서 표시 코드 대조. 아래 검사 수는 기능별 구현 당시의 중간 기록이다.

- 2026-09-10 중간 검증: 원본 순수 함수 검사 132개(7개 파일), 원본 전자책 변환기 검사 6개 통과. 검색·품질·채팅·문서 표시·현대 문서 추출·MinerU·이미지 설명 관련 통합 40개 통과. 위키 생성 20개도 별도 실행에서 통과했다. 아직 이번 변경의 전체 회귀 검사를 마친 것은 아니다.
- 생성 페이지 수 40개와 순환 묶음 5개 제한을 제거했다. 6개가 서로 참조하는 페이지를 하나의 검토 묶음으로 생성·게시하는 양성 검사를 추가했다.
- 단일 원문 소유 페이지는 원본처럼 본문을 교체하고 이전 버전을 보존한다. 여러 원문이 기여한 페이지는 원본의 `mergePageContent`와 프롬프트로 병합한다. 기존 덧붙이기 기대값 대신 두 경우를 분리하여 확인했다.
- 원본의 구조 점검(`computeStructuralLint`)과 예외 설정을 이식했다. 의미 점검은 현재 제목·별칭 목록을 함께 읽어 이미 있는 페이지를 새 페이지로 제안하는 경우를 걸러낸다.
- Linux Docker 변환기 빌드와 실제 운영 기반 이미지의 DOCX 본문·표 변환을 확인했다. 실제 OCR 제공자·Vision 모델의 업무 정확성은 아직 확인하지 않았다. 로컬 MinerU/멀티모달 응답은 전용 시험 서버로 프로토콜·검색·접근 제어를 확인했다.
- 문서·이미지 및 폴더/URL 설정은 [가져오기·변환 안내](ORIGINAL_IMPORTS_AND_PARSERS.md)를 따른다.

- 폴더·URL 통합 4개 통과: 동시 중복 등록, 하위 폴더별 자료 구분, 변경·과거 내용 복원, URL 이동·내부망 차단·검토 전 비공개, 서버 감지의 이동·삭제·담당자 권한 철회, 390px 실제 폴더 등록. 현재 버전과 과거 버전의 같은 해시를 구분하도록 DB 유일 제약을 조정했다.
- 프로젝트 ZIP 통합 4개 통과: 실제 원본 구조의 왕복·숨김 파일/빈 폴더/그림 보존, 새 도메인의 원문 처리·근거 연결·동료 승인, 철회 후 목차/로그/그림 접근 갱신, 경로 이동·중복·심볼릭 링크·CRC 손상·목차 누락 및 권한 거부, 390px 실제 ZIP 업로드와 문서 링크 이동. 원본 함수 비교 검사는 집계 함수 2개를 포함하여 134개가 통과했다. [프로젝트 문서·ZIP 안내](ORIGINAL_PROJECT_ARCHIVE.md)에 파일 구조와 검토 절차를 기록했다.
- 기존 원문 개정 시 연결 위키를 40개로 제한하던 마지막 조회·오류도 제거했다. 도메인 목적/스키마/개요와 한글 위키의 API 바이트 한도를 폼의 문자 수 한도에 맞춰 조정했다.
