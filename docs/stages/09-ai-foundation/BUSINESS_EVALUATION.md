# 실제 자료 평가표

개발 표본 검증과 실제 업무 승인은 별도로 기록한다. 현재 실제 고객 문서와 업무 담당자의 판정은 제공되지 않았다.

| 입력 | 값 |
| --- | --- |
| 평가 담당자·검토자 | 미입력 |
| 원문명·버전·공개 승인일 | 미입력 |
| 작업공간·도메인·프로젝트 | 미입력 |
| 모델·설정 지문·입력 상한 | 실제 시험 시 기록 |
| 중요 부정문·수치·단위·예외 | 미입력 |
| 기대 위키·중복 또는 모순 후보 | 미입력 |
| 답할 수 없는 질문·추가 자료 | 미입력 |

| 판정 항목 | 통과 조건 | 실제 업무 결과 |
| --- | --- | --- |
| 원문 범위 | 끝부분·표·각주 포함, 제외 범위 명시 | 미검증 |
| 근거 검색 | 고정 질문의 기대 원문이 상위 근거에 포함 | 미검증 |
| 답변 사실 | 수치·부정·대상·예외를 바꾸지 않음 | 미검증 |
| 범위 구분 | 다른 프로젝트·미공개 원문을 혼합하지 않음 | 미검증 |
| 근거 부족 | 확인할 수 없는 답을 확정하지 않음 | 미검증 |
| 변경안 유용성 | 기존 지식에 필요한 보완이며 중복을 만들지 않음 | 미검증 |
| 인용 위치 | 실제 공개 원문의 해당 구절을 열 수 있음 | 미검증 |
| 운영 | 시간·토큰·미확인 사용량·복구 결과 기록 | 미검증 |

통과·수정 필요·보류 중 하나를 담당자가 기록하고 이유와 원문 구절을 남긴다. AI가 만든 문제 후보나 개발 시험 결과를 담당자의 승인으로 대체하지 않는다. 16단계 최종 완료표에도 실제 업무 검토가 없으면 해당 칸을 비워 둔다.
