# 3단계 검증 기록

날짜: 2026-09-09. 실제 회사 모델·고객 문서는 미제공 상태다.

## 시험 환경과 구분

- 개발 서비스: 3010, 개발 DB `domain_wiki`.
- 통합시험: 프로덕션 빌드 3101, 별도 DB `domain_wiki_test`.
- 모델 계약 시험: 로컬 전용 3102의 `scripts/mock-model.mjs`. 고정된 인공 응답과 4차원 벡터를 사용한다. 실행 종료 시 종료하며 운영에 사용하지 않는다.
- 전체 명령: `npm run test:integration`. 특정 단계 재현: `node scripts/test-integration.mjs --grep '3단계'`(최신 빌드 필요).

## 검증 범위

- 본인 대화 저장, 관리자·작성자·다른 공간 계정의 직접 API 접근 차단.
- 선택한 도메인·프로젝트·자료 범위 검사와 질문별 범위 이력.
- 공개 자료의 pgvector 저장, 키워드·벡터 순위 결합, 현재 게시 상태 재검사.
- UTF-8 문자가 분할된 SSE, 마지막 줄 개행이 없는 완료 레코드, 사용량 저장.
- 인용 ID 검증, 중복 요청 재생, 후속 문맥, 피드백의 검토함 전달과 개인 본문 비공개.
- 잘못된 인용, 모델 오류, 완료 전 연결 끊김, 중지, 동시 질문과 범위 변경 충돌.
- 실제 브라우저의 질문·근거 열기·새로고침, 390px 가로 넘침과 JavaScript 오류.
- 근거가 없는 질문의 명시적 응답 불가, 임베딩 장애의 키워드 대체, 모델 점검 API의 관리자 권한.
- 진행 중 직원 권한·원본 공개 상태 철회와 과거 답변 숨김.

## 발견하고 수정한 문제

1. 웹 화면 권한 모듈을 색인 작업자가 가져오면서 Next.js의 화면 실행 코드가 Node 작업자와 충돌했다. DB·모델·색인 부분을 화면 의존성 없는 모듈로 분리하고 별도 프로세스 시작을 검증했다.
2. 색인 CLI의 최상위 await가 프로젝트의 CJS 변환 방식에서 동작하지 않았다. 다른 운영 스크립트와 동일하게 비동기 main 함수로 수정했다.
3. 기존 1단계 시험이 채팅의 ‘준비 중’ 버튼을 기대했다. 실제 입력 가능 화면으로 동작이 바뀌어 기대값을 갱신했다.
4. 이전 답변의 근거가 현재 검색 목록과 다를 수 있어, 이번 실행에서도 근거를 모두 확인할 수 있는 이전 답변만 모델 문맥에 넣도록 제한했다.

## 실행 결과

- 프로덕션 빌드·TypeScript·Biome(103개 파일)·Git 공백 검사 통과.
- 전체 통합시험 **27개 통과, 37.6초**. 기존 1~2단계 18개와 3단계 9개를 함께 실행했다.
- 빈 임시 DB에서 마이그레이션을 두 번 실행해 이력 3개·업무 테이블 21개를 확인했다. 임시 DB는 시험 후 제거했다.
- 개발 3010 화면에서도 자료→질문 이동, 모델 미설정 안내, 실패 상태 저장·재열기, 390px 넘침 없음, JavaScript 오류 0을 확인했다.
