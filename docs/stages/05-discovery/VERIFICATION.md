## 검사 중 발견하여 수정한 사항

- PDFParse의 표 감지가 브라우저 PDF의 얇은 채움 테두리를 놓쳤다. PDF.js 공개 API를 이용한 테두리 격자 보완을 추가하고, 원본 표본의 실제 행·열 결과로 재검사했다. 표를 감지하지 못하면 명확하게 수동 대조를 안내한다.
- 다른 공간의 자료는 존재를 드러내지 않는 404를 반환한다. 신규 시험의 403 기대값을 실제 접근 정책에 맞게 바로잡았다.
- 신규 홈 화면 시험에 링크가 없어야 한다는 잘못된 기대값이 있었다. 표시와 도메인 범위 URL을 검사하도록 수정했다.
- 모바일 시각 확인에서 안내 패널 간격과 동의어 줄 나눔을 보완했다.

## 남은 품질 평가

P5-01·P5-02의 기능·권한·화면 검증을 완료했다. P5-03·P5-04는 고객 자료와 회사 모델을 확보한 뒤 판정한다. 개발 표본 통과는 고객 문서 전반의 추출 정확도나 AI 응답 품질을 보증하지 않는다.

필요 입력: 실제 필수 문서 형식과 대표 원본(특히 병합 셀·각주·그림·변경 추적·다단 PDF·복잡한 PPTX), 회사 모델·임베딩 설정, 담당자가 판정할 고정 질문과 새로운 질문. 기존 [기준 질문 9개](../../evaluation/questions.json)에 대한 실제 모델 평가는 아직 실행하지 않았다. 이번 동의어 5조건·후속 질문 계약 검사를 그 평가로 대신하지 않는다.

다음 작업: 6단계 원본 개정의 영향 조회, 검토 담당·오류 신고 처리, 운영·사용량·보존 관리.
