## 시험 과정에서 수정한 사항

- 반복 로그인 때문에 전체 시험에서 로그인 요청 제한이 발생했다. 유효한 기존 세션을 먼저 확인하고 필요한 계정만 재로그인하도록 시험 준비를 수정했다. 서비스의 로그인 제한은 유지했다.
- 변경안 항목을 제거할 때 다른 항목의 폼 상태가 섞이지 않도록 항목별 안정적인 키를 사용한다.
- 생성 작업 완료와 변경 묶음을 함께 저장하고, 작업이 이미 끝난 경우 새 묶음을 남기지 않도록 검사한다.
- 묶음의 긴 한국어 본문을 처리할 수 있도록 해당 생성 요청의 JSON 한도를 384KiB로 분리했다. 다른 API의 기본 64KiB 한도는 유지한다.

## 개발 서버·DB 재현

`http://localhost:3010`에서 개발용 진술을 실제 저장·추출·승인하고 개정 화면을 열었다. 모델 미설정 안내, 390px 가로 넘침 없음, JavaScript 오류 0을 확인했다. 이 자료는 제목과 본문에 개발 예시임을 표시했으며 실제 고객 업무 사실로 취급하지 않는다.

빈 임시 DB에 전체 마이그레이션을 2회 실행했다. 이력 4개, 업무 테이블 24개를 확인했고 임시 DB는 정리했다.

## 남은 실제 평가

P4-02의 회사 모델 초안 생성 품질, P4-04의 메모 사실 보존·의미상 중복·모순 평가는 모델 설정과 고객 자료가 필요하다. 계약 표본 통과로 이를 완료 처리하지 않는다. 추가 승인 없이 5단계의 도메인 탐색·문서 품질 보완을 진행한다.

강제 연결 종료 시험에서 Next.js의 `The destination stream closed early` 전송 종료 로그가 한 차례 발생했다. 중단 상태·재요청·브라우저 검증은 통과했으며, 운영 로그 정리는 6단계에서 확인한다.
