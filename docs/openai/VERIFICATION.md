# OpenAI 실제 연결 확인

확인일: 2026-09-09. 사용자가 `.env`에 입력한 키를 서버에서 읽어 확인했다. 키 값은 출력하거나 기록하지 않았다.

- OpenAI의 채팅 모델 `gpt-5.6-terra`와 임베딩 모델 `text-embedding-3-small`에 대한 접근 확인: HTTP 200.
- 앱의 실제 모델 호출 함수로 간단한 문장을 보내 ‘연결 확인’ 응답을 받았다.
- 실제 임베딩 요청은 1536차원 벡터를 반환했다.
- 웹 서버와 문서 작업자를 새 환경설정으로 재시작했다. `/api/health`는 정상이며, 확인 시점에 작업자가 현재 모델의 임베딩 33개를 저장했다.
- 실제 브라우저에서 개발 예시 자료를 선택하고 질문했다. 결합 검색(`hybrid`)으로 근거를 찾고, 답변 상태 `completed`, 사용한 근거 3개, 답변 367자를 확인했다.
- 인용 버튼으로 원문 패널을 열어 버전 링크를 확인했다. 브라우저 JavaScript 오류는 없었다.
- 확인용으로 만든 대화는 시험 후 삭제했다. 기존 대화와 자료는 유지했다.
